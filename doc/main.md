# 骑士工坊 · 主体

纯前端挂机。定位：**抽工人、排流水线、同站堆人加速**。第一期纯生活；偶遇敌人「出发」只做补给门闩，真战斗后做。

工程对齐同作者 idea3_hospital：Vue3 + TypeScript + Vite + Pinia + Vitest，`src/sim` 纯逻辑，`src/ui` 薄门面，在线与离线都走同一个 `applyTick`。不复制医院的房间 / 污染 / 病人。GitHub Pages 为 project site，Vite `base` 为 `/idea5_idle/`，在线地址 https://sung1011.github.io/idea5_idle/ ，推 `main` 即部署。

另见：[生产定稿](production.md)、[分阶段落地](todo.md)、[站点等级与品类](stationProgress.md)。七工坊、工人双槽、钓鱼细则与明确不做以 production 为准。第 2 期已落地采集四差异；第 3 期已落地锻造软失败与工具槽；第 4 期已落地烹饪食物槽与生产 Buff；第 5 期已落地炼金占位（耗草 / 猎副产出 `potion`，效果不填）与打磨。炼金效果数值仍后补。

游戏定名 **骑士工坊**（仓库名 `idea5_idle` 可保留）。主界面拆成页签（无路由库）：**工坊** / **工人** / **偶遇**，页签固定在屏幕最下方（移动端 `min-height: 48px`）。顶栏只留金币 / 钻石 / 工人数、消息、设置，不做跨站状态清单、日时钟或玩法说明。设置弹框分页：**统计**（游戏日 / 已运行 / 探索 / 出发 / 抽人 / 离线次数）、**常规**（音乐 / 音效开关，先记本地 preference）、**GM**（初始化与加资源，仅调试）。钻石 `diamonds` 是高级代币占位，默认 0。停产靠站点卡片红框（只剩缺料）；共振在对应卡片标「共振」。物资数量在各站卡片就近看（该站 `costs` / `outputs` 相关物品）；主界面不再卖货。没有银行页，也没有容量条。

## 1. 定位

一存档是一个账号：共用物资库存、工人名册、统一时钟。金币只服务生活（抽人 / 探索 / 黑心商人购买消耗，当铺典当 / 收购 / 敌人战利品加金），不接战斗。

- **Worker**：抽取获得。带 `qualityTier` 1～10（颜色档）与 `classId` 占位；第一期不当战斗成长用。同档两人可合成升一档。
- **生活站点（定稿七站）**：挖矿 `mining`、锻造 `forging`、狩猎 `hunting`、烹饪 `cooking`、采药 `herbalism`、炼金 `alchemy`、钓鱼 `fishing`。采集 / 制造各有核心差异，经同一套物资库存连成流水线。细则见 [production.md](production.md)。
- **现码已是七站骨架**：采矿、锻造（工具）、狩猎、烹饪、采药、炼金、钓鱼。伐木 `woodcutting` 废弃并藏入口；旧档已派伐木的工人 hydrate 撤到休息。
- 锻造主产物改为生产工具，进物资后再装 `toolSlot`。软失败扣部分矿、无成品、给少量 XP。匹配当前工坊才吃常驻增效；空槽或不匹配 = 裸效率，仍可派。**武器线搁置**。`foodSlot` 装烹饪食物，同时仅 1 个生产 Buff；到期槽内还有则自动吃 1 份刷新，可立即换食覆盖。偶遇补给收食物 / 工具 / 矿。

三条主轴：

1. **跨站流水线（定稿）**：挖矿 → 矿石 → 锻造工具 → 工人 `toolSlot`；钓鱼 / 狩猎 → 烹饪食物 → 工人 `foodSlot`；采药 / 狩猎副产 → 炼金出 `potion` 占位（第 5 期已能做，效果不填）。第 2 期采集已按节点 / 空杆 / 遇险 / 稳采结算；第 3 期工具槽已生效；第 4 期食物槽续 Buff，与工具词条同 `effectId` 取最强；炼金解析口 `potionEffectValue` 本阶段恒为 0。
2. **同站堆人加速（迅雷手感）**：同一站点可派多个 worker，人越多该站进度 / 吞吐越快。
3. **工坊共振**：相邻站同时有人 → 下游少空转、额外产出。定稿邻接：挖矿↔锻造；钓鱼/狩猎↔烹饪；采药↔炼金。
4. **堵点可见**：原料见底提示。物资无容量，堆再多也不停产。不恢复银行容量停产。

### 2.2 Worker

第 3 期 `toolSlot` 已吃常驻增效（匹配工坊才吃满）；第 4 期 `foodSlot` 续期：

```ts
Worker = {
  id,
  name?,
  classId?,          // 占位，不当战斗成长
  qualityTier,       // 1～10；抽人默认 1；旧档缺字段 hydrate 补 1
  assignment: stationId | null,
  toolSlot: ToolSlot | null,   // 常驻增效；匹配工坊才吃满；空/不匹配=裸效率可派
  foodSlot: FoodSlot | null,   // 烹饪产物；同时仅 1 个生产 Buff；到期自动吃 1 份刷新；可立即换食覆盖
}
```

品质 10 档写在 `WORKER_QUALITY_TABLE`，UI 用档色一眼区分（扩自偶遇灰绿蓝紫橙）：

| 档 | id | 名 | 色 |
| --- | --- | --- | --- |
| 1 | `gray` | 灰 | `#9a8f7a` |
| 2 | `white` | 白 | `#c4bba8` |
| 3 | `green` | 绿 | `#3e9a2a` |
| 4 | `blue` | 蓝 | `#3a7ad9` |
| 5 | `cyan` | 青 | `#1aa6a6` |
| 6 | `purple` | 紫 | `#8a4ecf` |
| 7 | `orange` | 橙 | `#e67a12` |
| 8 | `red` | 红 | `#d43a3a` |
| 9 | `gold` | 金 | `#d4a017` |
| 10 | `rainbow` | 彩 | `#e83e8c` |

合成：只允许**同档**两人。消耗两人，产出 1 个高一档新人；满档（10）不能再升。不同档失败。工具槽 / 食物槽按现有卸下回物资（食物只退槽内剩余份），新人休息、空槽。职业在「新档可用池」里用 `rngState` 随机：`minQuality ≤ 新档` 的 `classId` 都能抽到，可能是两人已有的，也可能是池里其它职业。1 档池仍是力工 / 匠人 / 游民；更高档依次解锁矿工、渔夫、猎手、厨子、药农、铁匠、炼金师、管事、骑士。名字仍按 `WORKER_NAME_POOL` 与 `nextWorkerId` 轮转。本档品质只区分外观与职业池，不改吞吐公式。

特效可来自工具或食物：同 `effectId` 取最强，不同 ID 并存；炼金走同一套 `effectId` 解析口（`potionEffectValue`），本阶段恒为 0。同一 worker 同时只能派一个站。多个 worker 可以派到同一站。

### 2.3 站点

定稿七站（差异与去向见 [production.md](production.md)）：

| 站点 | `stationId` | `kind` | 核心差异 | 产出 → 去向 | 相邻（共振） |
| --- | --- | --- | --- | --- | --- |
| 挖矿 | `mining` | gather | 节点生命，挖空等恢复 | 矿石 → 锻造 | 锻造 |
| 锻造 | `forging` | craft | 配方 + 软失败 | 生产工具 → `toolSlot` | 挖矿 |
| 狩猎 | `hunting` | gather | 遇险检定（非战斗） | 肉 → 烹饪；血/牙/眼 → 炼金 | 烹饪 |
| 烹饪 | `cooking` | craft | 产出食物 | 食物 → `foodSlot` → 生产 Buff | 钓鱼、狩猎 |
| 采药 | `herbalism` | gather | 无限稳采 | 草 → 炼金；香料 → 烹饪 | 炼金 |
| 炼金 | `alchemy` | craft | 一次性消耗草 / 血 / 牙 / 眼（效果未定） | `potion` 占位 | 采药 |
| 钓鱼 | `fishing` | gather | 可空杆；期望更慢；随机；渔场品阶墙 | 鱼 → 烹饪；杂物低权 | 烹饪 |

**旧站**：伐木 `woodcutting` 已移出主界面与派站按钮。hydrate 把已派伐木的工人撤到休息。`wood` 旧档数量保留、可在偶遇出手，不再产出。不做制皮 `leatherworking`。

现码 UI 主玩七站：采矿→锻造、钓鱼/狩猎→烹饪、采药→炼金（已升主列，无骨架折叠）。锻造出工具（铜/铁/秘银档），可软失败；工人页可装备/卸下工具，也可选食物与数量装 `foodSlot`。挖矿有节点生命，挖空后该矿恢复中可换其它已解锁矿；钓鱼按渔场掉落（可空杆、初级不出高阶）；采药无限稳采草/香料；狩猎周期结束做遇险检定（短暂停手 / 本次减产，无战斗 UI）。烹饪：烤鱼耗鱼出 `meal`，烤肉耗肉出 `roast`（开局可做），香料炖耗肉/鱼+香料出 `stew`（Lv5）。炼金耗草或猎副产（血/牙/眼）出 `potion`，不能装食物槽、不加生产 Buff。

采矿 / 锻造 / 钓鱼 / 狩猎 / 烹饪各站独立等级与 XP。采矿 / 锻造 / 钓鱼 / 狩猎开局只解锁第 1 品类，每 5 级解锁下一档；烹饪开局解锁烤鱼与烤肉，Lv5 解锁香料炖。高阶是新物品，不是换皮。整站只选一个品类，堆人加速当前档。采药 / 炼金仍单一品类。周期全部 ×4（不足 20s 提到 20s）。升级 `xpToNext(L) = round(100 * 1.45^(L-1) * 0.175)`，铜/铁/秘银每次 1/2/3 XP，到 Lv5 累计 133，前期升档墙钟比旧周期+旧 XP 大约快 30%。细则见 [stationProgress.md](stationProgress.md)。

原料不足则空转并提示缺哪几样，够则一次性扣光 `costs` 再产出。产出不受库存数量限制。

偶遇敌人新单改收食物 / 工具 / 矿。旧档武器需求仍可成交。

## 3. 同站堆人加速

进度记在站点。每秒：

```
stackFactor(n) = n
speed = (1 / cycleS) * stackFactor(n) * (共振 ? 1.2 : 1)
progress += speed
progress >= 1 → 完成一次吞吐，progress -= 1
```

例：采矿 `cycleS = 20`

- 1 人：`speed = 0.05/s`，20 秒出 1 矿
- 3 人：`speed = 0.15/s`，同等时间 3 倍吞吐（约 6.67 秒出 1 矿）

`cycleS` 取当前 `selectedCategory`。没人的站不推进。原料见底（锻造高阶档缺对应矿也算）时进度冻结，并写 `stallReason: emptyInput`。产物再多也不停产，没有满仓。

## 4. 流水线与共振

定稿主轴见 [production.md](production.md) 第 3～4 节。现码主轴：采矿把当前品类的矿推进物资（挖空等恢复）→ 锻造扣对应矿出工具；钓鱼按渔场随机出鱼/杂物/空杆、狩猎出肉 → 烹饪出熟食/烤肉/香料炖进 `foodSlot`；采药出草/香料、狩猎出副产 → 炼金扣草或血/牙/眼出药剂占位。共用 `RESONANCE_SPEED_MUL` / `RESONANCE_BONUS_EVERY`。

共振：`STATION_DEF.neighbors` 两端同时有人。邻接已改为挖矿↔锻造、钓鱼/狩猎↔烹饪、采药↔炼金。

- 双方速度 × 1.2（下游少空转）
- 共振期间每完成 4 次吞吐，主产物额外 +1；锻造额外再掉 1 张图纸

配方 `costs`：`IoRule[]`，三种形态同一套结算。

1. 单料 1 个：`[{ itemId: 'ore', qty: 1 }]`
2. 同料 n 个：`[{ itemId: 'ore', qty: n }]`
3. 多料：`[{ itemId: 'ore', qty: n }, { itemId: 'wood', qty: m }]`

`takeCosts` 先看齐再扣；缺任一原料整单不扣，提示列出缺的物品。铜器另有 `altCosts`（渣滓）。

堵点（只剩缺料，没有满仓）：

- 当前锻造品类 `costs` 见底 → 锻造空转（铜档工具仍可用渣滓；铁/秘银只缺对应矿）
- 当前烹饪菜谱原料见底 → 烹饪空转（烤鱼缺鱼；烤肉缺肉；香料炖缺肉/鱼或香料）
- 草与猎副产都见底 → 炼金空转（卡面写「草 / 血 / 牙 / 眼见底」）
- 采集站不因物资数量停工

各站卡片就近显示该站产出 / 消耗物资数量，没有独立物资区、容量条 / 快满 / 满仓。数量可无限（仅 `MAX_SAFE_INTEGER` 软夹，防溢出，UI 不表现满）。库存仍写 `save.bank`。

## 5. 抽人

表驱动。扣 `RECRUIT_COST`（15）金币，按 `WORKER_NAME_POOL` / `CLASS_PLACEHOLDERS` 轮转写花名册，`qualityTier = 1`。金币不够失败，不写工人。

同档两人可在工人页合成升档，见 2.2。

主界面不再卖货（无整批「卖货」、无单件「卖 1」）。流水线制品的主去处是偶遇敌人补给（见第 6 节）；换金走当铺典当与收购。`sellFromBank` / `sellAllGoods` 仍留在 `src/sim`，仅调试 / 单测。

## 6. 偶遇（探索 + 六种订单 + 品质，不是战斗）

偶遇板固定 **6 格**，同时展示 6 张货单。页签 / 面板标题用「偶遇」。主动重抽叫 **探索**（消耗金币）。订单类型用现有：`enemy` 敌人、`blackMerchant` 黑心商人、`passerby` 路人、`pawn` 当铺、`artisan` 工匠委托、`bulkBuy` 收购。每种带 5 档品质 `gray / green / blue / purple / orange`（灰绿蓝紫橙）。**探索永不刷灰**（权重 0）；绿最多、蓝次之、紫少、橙很少。品质倍率写在 `QUALITY_TABLE`：绿=基准 1.0，蓝需求 1.25 / 产出 1.4，紫 1.6 / 2.0，橙 2.2 / 3.0（性价比 = 产出/需求递增）。高品质需求更高、产出更高、更赚。成交 / 敌人已领奖的格子盖章（成交 / 完成 / 已领）并换底色，主按钮不可再点。失败/拦截提示用点击附近漂字，不占死栏。

### 6.1 探索

`EXPLORE_COST_TABLE` 表驱动：`[8, 10, 12, 14, 16]`，按 `exploreCount` 取档，超出末档钉在 16。金币不够不能探索，不换板。成功则扣金、`exploreCount++`，按新种子重抽，**只替换可刷新格**；保留格占原位，板子仍满 6 格。

敌人格：

- **保留不刷新**：行军倒计时中，或行军已结束、战利品未领。
- **可以刷新替换**：未出发，以及战利品已领取。

交易格（黑心商人 / 路人 / 当铺 / 工匠委托 / 收购）：未完成与已完成都可刷新。当前没有未结清的跨格交易。

### 6.2 敌人

带远近（`distance`: 近 / 远）与强弱（`power`: 弱 / 强）。

- 远 → 更高食物 / 干粮（熟食、鱼）
- 强 → 更高矿物（铜矿；武器搁置）

定稿：补给暂改食物 / 工具 / 矿等已有物，武器搁置。第 1 期新单已按此改表。

流程（一键出发，没有「提交补给」中间步）：

1. 对照物资看补给；缺的标红。货不够则「出发」禁用；点了也失败，提示缺啥，**不扣货、不进入行军**。
2. 货够：一次点击扣光该格补给，`departCount++`、写 `lastDepartAt`、写 `marchEndsAt`（墙钟），该格标记 `departed`。**出发当时不发金币。**
3. 行军时长表驱动 `MARCH_DURATION_S`：近弱 10 分钟、近强 18 分钟、远弱 22 分钟、远强 30 分钟（远 / 强更久）。UI 主按钮变为倒计时（`行军中 mm:ss`）。
4. 倒计时结束（在线 tick / 离线追赶都按墙钟到期）：按钮变为「战利品」。
5. 点「战利品」：只发该格表驱动 `lootGold`（`LOOT_GOLD_TABLE`，按远近强弱），**不加物资**。该格 `lootClaimed = true`。
6. **不做伤害、战斗回合、失败死亡。** 行军只是等待门闩。

旧两步流程的 `submitted` 不再对玩家暴露。新档不写该字段。旧存档若已扣货未出发，hydrate 只保留 `submitted` 以免再扣；点「出发」直接进入行军。旧存档若已 `departed` 且没有 `marchEndsAt`（当时已发过补给金），迁成 `lootClaimed`，避免再发。

### 6.3 黑心商人 / 路人 / 当铺 / 工匠委托 / 收购

五种交易互斥，卡面标题用中文名，只渲染该类型允许的按钮。品质已在生成时写入需求 / 产出。

1. **黑心商人**（kind `blackMerchant`）
   - 只提供：玩家花金币购买对方货物
   - 不以物易物、不以物换钱
2. **路人**（kind `passerby`）
   - 只提供：以物易物
   - 不收金币买、不以物换钱
3. **当铺**（kind `pawn`）
   - 只提供：以物换钱（交出列出的物资，按价表换金币）
   - 报价表驱动：`pawnUnitGold = max(1, floor(sellGold * PAWN_RATE))`，`PAWN_RATE = 0.75`，略低于 `sellGold`；品质再乘产出倍率
   - 列出可典当物品与报价，确认后扣货加金；货不够失败、不扣错货
   - 不购买、不以物易物
4. **工匠委托**（kind `artisan`）
   - 提交指定成品，换金币 + 工坊临时产量 buff（配方系统未就绪，先不做限时配方）
   - buff 写入 `workshopBuff`，站点速度乘 `buffMul`，到期失效
5. **收购**（kind `bulkBuy`）
   - 高价收指定成品：玩家给物品换金币
   - `bulkUnitGold` 用 `BULK_BUY_RATE = 1.15`，单价优于当铺

成交后该格 `completed`（敌人领奖后 `lootClaimed`）。货不够 / 金币不够则失败。物资装得下任意换得货物，不再因「满」失败。

旧存档 `kind: 'shady'` / `'pawnshop'` 迁成 `blackMerchant` / `pawn`；通用 `kind: 'merchant'`：有收购+换得字段则迁成路人；只有金币购买则迁成黑心商人；否则默认路人。缺品质的旧格补 `green`。

### 6.4 开局与旧存档

新档生成初始 6 格偶遇。旧 5 格板补第 6 格（行军中/可领奖敌人原位保留）。旧存档若仍是单格出发（`currentOrderId` / `orderIndex` / `orderSubmitted`），生成 6 格并把旧需求迁进第 0 格敌人（旧档已扣货则内部记一笔，点出发不再扣）。旧的单格出发 / 两步补给流程已替换为一键出发。

## 7. 日循环与离线

- 1 tick = 1 秒。
- 1 游戏日 = 1440 秒（24 分钟现实时间）。只做显示，不改公式。
- 在线每秒 `applyTick` 一次；离线按秒数连跑同一个 `applyTick`。
- 离线上限 **8 小时**（`OFFLINE_CAP_S = 28800`）。超过的部分丢掉。
- `settleOffline` 对比结算前后物资 / 站点 / 金币，生成摘要。boot 与 `visibilitychange` 回前台时 catch-up。有变化时写入一条未读「离线收益」消息（时长、主要产出等），**不再强弹顶栏大摘要条**。顶栏「消息」按钮有未读红点。

`localStorage` 键名：`idea5Idle`。整份 `Save` JSON。
