# 骑士工坊 · 主体

纯前端挂机。定位：**抽工人、排流水线、一站一人加速**。主线敌人是补给开门闩后的时间轴战斗（HP / ATK / SPD），交易单不动。

工程对齐同作者 idea3_hospital：Vue3 + TypeScript + Vite + Pinia + Vitest，`src/sim` 纯逻辑，`src/ui` 薄门面，在线与离线都走同一个 `applyTick`。不复制医院的房间 / 污染 / 病人。GitHub Pages 为 project site，Vite `base` 为 `/idea5_idle/`，在线地址 https://sung1011.github.io/idea5_idle/ ，推 `main` 即部署。线上为 HTTPS，Chrome / Edge 可安装应用；iOS Safari 多为「添加到主屏幕」。开发服务不注册 Service Worker。manifest 的 `start_url` / `scope` 与 `base` 相同。

另见：[生产定稿](production.md)、[分阶段落地](todo.md)、[站点等级与品类](stationProgress.md)。现玩法六站（钓鱼已撤，鱼/杂物并入狩猎），工人食物槽与明确不做以 production 为准。第 2 期已落地采集差异；第 3 期工具槽已撤，改为铭刻一次性符文；第 4 期已落地烹饪食物槽；第 5 期已落地炼金随机七种药剂批次。食物主职是回血；7 种药剂装进工坊页 4 槽后点槽使用、点？看效果，无 CD。已删除站狂暴、战鼓药与站工具。狩猎真战斗本轮不做（TODO），现遇险扣血接到劳损。

## 1. 定位

一存档是一个账号：共用物资库存、工人名册、统一时钟。金币只服务生活（探索 / 黑心商人购买消耗，当铺典当 / 收购 / 部分敌人与商场订单 / 工坊吞吐按产出 `craftGold` 加金），不接战斗。抽工人花钻石。

- **Worker**：抽取获得。带 `qualityTier` 1～10（颜色档）与 `classId`（生活职业，战斗只做三围小修正）。同档两人可合成升一档。存 `hp` / `hpMax`（工坊与战斗共用）；hydrate 缺则按表满血。另存战斗 `level`（从 1）与当前级内 `xp`；hydrate 缺则 Lv1、xp 0。另存 `combatAttrs`（剑枪匕首斧弓杖 / 火冰雷风光暗），槽数看品质。
- **生活站点（现玩法六站）**：挖矿 `mining`、铭刻 `inscription`、狩猎 `hunting`、烹饪 `cooking`、采药 `herbalism`、炼金 `alchemy`。`forging` / `smithing` / `engraving` 只是铭刻别称。钓鱼 `fishing` 已废弃，与伐木一样 hydrate 撤派、清站状态；鱼 / 杂物改由狩猎产出。采集 / 制造各有核心差异，经同一套物资库存连成流水线。已删除站狂暴。细则见 [production.md](production.md)。
- **现码已是六站骨架**：采矿、铭刻（符文）、狩猎、烹饪、采药、炼金。伐木 `woodcutting`、钓鱼 `fishing` 废弃并藏入口；旧档已派这两站的工人 hydrate 撤到休息。
- 铭刻**只造一次性战斗符文**（`RUNE_DEF`：锋锐 / 厚甲 / 血酬 / 破障 / 迅击 / 洞悉），耗荒晶 `wildCrystal`。采矿各档双掉对应矿 + 荒晶；矿石走订单 / 金币，荒晶不进主线新单池。没有 20 档工具下拉，不按吞吐耗工具。**武器线搁置**。工人只留 `foodSlot` 装烹饪食物，主职回血（meal/roast/stew 约 25%/40%/55% hpMax）；到期槽内还有则自动吃 1 份刷新槽，残血（≤30%）自动吃 1 回血，可立即换食覆盖，无手动喂。生产加速压到很弱。偶遇补给收食物 / 符文 / 矿（新刷不再要工具；旧档工具 hydrate 转荒晶）。每站最多 1 人。同档可拖到休息区的人合成（在岗拖过去也行），新人回休息；拖到站上同档的人也会合成，新人留在该站。不同档或满档放不下，不换人。拖回休息区空白仍是撤岗。工坊站卡不再有狂暴。

三条主轴：

1. **跨站流水线（定稿）**：挖矿 → 矿石走订单 / 金币，荒晶 → 铭刻一次性符文 → 开战 1 槽；狩猎 → 肉/鱼 → 烹饪食物 → 工人 `foodSlot`（回血）；采药 / 狩猎副产 → 炼金随机出 7 种药剂批次（工坊页 4 槽装配后短按点用）。第 2 期采集已按节点 / 遇险 / 稳采结算；第 3 期站工具已撤；第 4 期食物槽续期。
2. **一站一人（迅雷手感）**：同一站点最多派 1 人。在岗正好 1 人时速度再 ×`SOLO_STAFF_MUL`（1.5）。第 2 人派入失败，文案「该站最多 1 人」。同站冲突废弃，`stationConflictMul` 恒为 1。
3. **堵点可见**：原料见底提示。物资无容量，堆再多也不停产。不恢复银行容量停产。

工人另存 `fatigueDebt`（劳损累计）。成功产出才加债：`+= (hpMax * 0.0015 + 近满血一口) * stationMul * comboMul`；`debt≥1` 时扣 `floor(debt)` 血并减掉对应债。近满血一口仅 `hp >= hpMax-1` 时加 `0.18`，让短时吞吐先看到掉 1～2 点，之后回落比例债。HP 最低锁 1。禁止每次产出无脑 `max(1, floor(hpMax*0.02))`。空转 / 空杆不加劳损。血线三档（`hp/hpMax`）：≤10% 空血 ×0.5，≤30% 残血 ×0.8，＞30% 正常 ×1。站内连招乘在劳损上，无跨站 combo。工人 v2 底色血条读 `hp - fatigueDebt`。

战斗等级只改三围，不改生产 / 品质。出战三围 = `WORKER_COMBAT_BY_TIER` + `CLASS_COMBAT_MOD`，再叠等级：相对 Lv1 每级 HP +4%、ATK +3%、出手间隔 ×0.99（最快不低于该底版的 70%），再按工人 id 哈希叠稳定间隔抖动（约 ±8%～12%），界面显示抖动后的 `Ns`。`xpToNext(L) = round(20 * 1.25^(L-1))`，可连升；`totalXp` / `fromTotalXp` 供合成。升级重算 `hpMax`，当前 `hp` 按升级前比例留到新上限。XP 两处发放，都走 `grantWorkerCombatXp`（可连升，升级按升级前血量比例重算 `hpMax`）。战胜后点「战利品」发给本场 `combat.workerIds` 里仍在名册的工人（含已写回且 HP≤0）；败战 / 未领 / 战斗中不发。发放量按阶级底值（杂兵 12 / 精英 20 / 首领 32）+ 每章 +1。工坊站**成功完成吞吐**（有产出）时，给该站 `assignment === stationId` 的在岗工人各发 `max(1, round(该次站 xpPerCycle × 0.35))`；已点「工匠密录」再 ×1.25（乘完至少比原份额多 1）。软失败 / 空杆 / 冻结无产出、助战与非在岗不发。站本身仍拿原来的站 XP，不改站 XP 曲线。合成仍是双方总经验相加，不走这次发放。升级（`levelsGained > 0`）时全局漂「{短名} 升至 Lv{N}」，该人在工坊页在岗槽 / 右栏短暂闪边（`level-flash`）。`workerLiveStats` / `fillWorkerHp` / `beginEnemyCombat` 都走带等级的算法。

工坊在岗工人与战斗共用这份 `hp`。日常扣血走**劳损累计**，不每次砍一截：

```
fatigueDebt += (hpMax * 0.0015 + nearFullPip) * stationMul * comboMul
HP -= floor(fatigueDebt)；fatigueDebt -= floor(fatigueDebt)
```

- `stationMul` 站基准约 0.4（铭刻成功略高 0.55），把 0.0015 落到极缓日常。`nearFullPip` 仅 `hp >= hpMax-1` 时为 `0.18`，否则 0：短时先扣出 1～2 点，之后只走比例债。测例：单人裸效率，满血模拟 6h 等价产出（采药 1080 次）后 HP 仍 ≥2。工人 v2 底色按 `workerWearHp = hp - fatigueDebt` 铺，成功吞吐未扣整数 HP 时条也会从满绿改缺口。
- `comboMul` 只站内：采药连续成功倦意缓慢加重；烹饪同菜连锅加重、换菜重置、炖 ×1.25；采矿深挖递增，挖空额外一口，恢复期不计入；钓鱼空杆不加、上鱼才加、连竿加重；铭刻成功重、软失败轻但叠挫败，下次成功清算；炼金站级毒雾加重后续劳损，停产衰减；狩猎成功按基准，现遇险接到劳损（轻债），**真战斗 TODO 不做**。
- 空转 / 空杆 `kindMul=0`。软失败 ×0.35，遇险 ×0.5。
- HP 最低锁 1，不自动下岗、不打死。双人站各自记自己的债。食物不再减工坊掉血。成功产出后若仍残血（hp/hpMax ≤30%，含空血）则该站卡另漂「虚弱」。站卡进度行另写「效率 N%」（空岗 100%，两人取更低乘区）。账号首次在岗效率跌破 100% 时全局漂一次「工人体力不足，工坊效率下降。装备熟食可自动回血；紧急可用药剂。」并记 `workshopHpEfficiencyTipShown`。工人v2 左右栏底色血条读 `workerWearHp`（`hp - fatigueDebt`）。

站工具已撤，速度乘区恒 1。食物生产加速压到很弱（熟食 ×1.02 / 香料炖 ×1.03，烤肉不再额外产），主职是回血：`ceil(hpMax * 比例)`，meal 25% / roast 40% / stew 55%，至少使 HP>1。残血（hp/hpMax ≤30%）且槽内有余粮则自动吃 1：工坊在岗产出扣血后检查，主线等战斗结算后也按残血检查。工坊页只留装槽 / 换食 / 卸下，不提供「吃 1 / 手动喂」。药剂必须装进工坊页 4 个 `potionSlots` 后点槽使用（扣物资 1 瓶，无 CD；库存 0 仍留装配；点「？」看效果，装配面板只写名字和数量）。点槽只作用于六站在岗；战斗中 / 休息 / 助战不吃；无人在岗漂「没有在岗工人可用药」且不扣瓶。7 种：`stim` 兴奋剂（在岗速度 ×1.5 / 3 分钟）、`salve` 回春散（在岗立刻回 10% hpMax）、`renewSoup` 续命汤（在岗存活每 10s 回 5% / 2 分钟）、`brinkSalve` 绝境膏（在岗 HP≤30%max 抬到 40% hpMax，否则立刻回 5% hpMax）、`rushPowder` 赶工粉（随机一个有在岗的工位，下一次产出周期缩短 40%，用完即清）、`doubleMist` 双份雾（随机一个有在岗的工位，下一批成功产出 80% ×2 / 20% ×3，用完即清）、`clearMind` 醒神散（只奶在岗最残的 1～2 人：第 1 人回 35% hpMax，第 2 人若 HP≤50%max 再回 20%；满血不选，无人可奶不扣瓶）。兴奋剂与续命汤时效按 `elapsedS` 走，离线追赶同一套。旧档通用 `potion` hydrate 成 `salve`；旧档 `focusDraft` / `wardElixir` 库存与已装槽迁成 `doubleMist` / `rushPowder`（旧时效不保留）；旧档 `warDrum` 槽清空。同一 worker 同时只能派一个站。每站最多 1 人。旧档工人 / 站上 `toolSlot` / `*ToolNN` hydrate 转荒晶与起步符文，不再装配；同站超过 1 人的只留先派的 1 人，其余撤到休息。工坊页没有工具装配。

## 3. 同站堆人加速

进度记在站点。每秒：

```
stackFactor(n) = n
人数项按工人加权：每人贡献 = 工具/食物速度乘区 × HP 效率
HP 效率：hp/hpMax ≤10% 空血 ×0.5；≤30% 残血 ×0.8；＞30% 正常 ×1
speed = (1 / cycleS) * 加权人数项 * soloStaffMul * groupStaffSpeedMul * 兴奋剂
兴奋剂：工坊页药剂槽点用（须有在岗工人），在岗速度 ×1.5，持续 180s（`elapsedS`）
存档：StationState.fatigueCombo；账号 `potionSlots` / `potionBuffs`
progress += speed
progress >= 1 → 完成一次吞吐，progress -= 1
```

例：采矿 `cycleS = 20`，在岗 1 人

- `soloStaffMul = 1.5`，`speed = 0.075/s`，约 13.3 秒出 1 矿
- 0 人：不推进
- 已点「工坊规章」：全站周期再 ×0.95（与骑士周期乘区叠乘）
- 已点「工匠密录」：成功吞吐时在岗工人经验 ×1.25（1 点经验至少变成 2，避免四舍五入吃掉）
- 已点「轮值章程」且同组两站都有人：该组速度再 ×1.08
- `stationConflictMul` 恒为 1，不再减冲突

`cycleS` 取当前 `selectedCategory`。没人的站不推进，且 `assignedCount <= 0` 时立刻把 `station.progress` 置 0（站卡条读同一字段，一起归零）；再派人从 0 涨。原料见底（铭刻缺荒晶，或已解锁配方都付不起）时进度冻结，并写 `stallReason: emptyInput`。产物再多也不停产，没有满仓。

## 4. 流水线

定稿主轴见 [production.md](production.md) 第 3～4 节。现码主轴：采矿把当前品类的矿 + 荒晶推进物资（挖空等恢复）→ 铭刻扣荒晶出随机已解锁符文；狩猎出肉/鱼（低权杂物）→ 烹饪出熟食/烤肉/香料炖进 `foodSlot`；采药出草/香料、狩猎出副产 → 炼金扣草或血/牙/眼出药剂占位。相邻站同时有人不再加速、也不额外掉主产物。`STATION_DEF.neighbors` 已清空，结算不读。

配方 `costs`：`IoRule[]`，三种形态同一套结算。

1. 单料 1 个：`[{ itemId: 'ore', qty: 1 }]`
2. 同料 n 个：`[{ itemId: 'ore', qty: n }]`
3. 多料：`[{ itemId: 'ore', qty: n }, { itemId: 'wood', qty: m }]`

`takeCosts` 先看齐再扣；缺任一原料整单不扣，提示列出缺的物品。铜器另有 `altCosts`（渣滓 1:1）。点亮「渣滓回炉」后，含铜矿的配方额外可按 2 渣滓 = 1 铜矿付账。

堵点（只剩缺料，没有满仓）：

- 荒晶见底或已解锁符文都付不起 → 铭刻空转
- 当前烹饪菜谱原料见底 → 烹饪空转（烤鱼缺鱼；烤肉缺肉；香料炖缺肉/鱼或香料）
- 草与猎副产都见底 → 炼金空转（卡面写「草 / 血 / 牙 / 眼见底」）
- 采集站不因物资数量停工

制造站卡片就近列出当前这次会扣的物品，不写「消耗库存」标题；采集无消耗则不列。产出靠吞吐完成时挂在对应工坊站卡的本地「获得」漂字，不走全局居中 `floatTips`，不常驻产出列表。没有独立物资区、容量条 / 快满 / 满仓。数量可无限（仅 `MAX_SAFE_INTEGER` 软夹，防溢出，UI 不表现满）。库存仍写 `save.bank`。

## 6. 主线（章节 + 探索 + 六种订单 + 品质；敌人是战斗）

PVE 底栏文案是「PVE」（内部 id 仍是 `encounters`）；面板内用科技树同款胶囊分页 **战场 | 地牢 | 商场**（记忆键 `idea5IdleMainlineTab`，不进存档，默认战场；旧值 `mine` 回落战场），同一行右侧共用 **简 | 详** 胶囊（记忆键 `idea5IdleMainlineDensity`，不进存档，默认详，三页同一偏好，切页不改详略）：详是现在这张完整卡；简只留标题、品质角标、消耗、获得、主按钮，战斗中另留血条、弱点与破防盾。敌人格（战场与地牢）卡头不写类型字「敌人」，简/详都留订单名字，并留杂兵 / 精英 / 首领或地牢标签；敌人格词条芯片并进卡头 tags（与阶级同一行，不另占一行），约 12px、1px 边框，点开气泡不变。地牢词缀写在各自订单卡头 tags（每单 2 条），顶栏写「今日两单」，开战后加「已开战 n」。商场等其它种类仍写中文类型名。地牢不占战场格、不被探索刷新。两板独立格数：**战场**初始 2、科技加到最多 4（`battlefieldSlotCount`）；**商场**初始 2、科技加到最多 4（`marketSlotCount`）。两板订单列表 CSS grid 固定两列换行，一行最多 2 张卡。战场只刷 `enemy`（杂兵 / 精英 / 本章 Boss）；商场只刷交易单（`blackMerchant` / `passerby` / `pawn` / `artisan` / `bulkBuy`）。章节行写 `第 N 章`，下面一条羊皮纸进度条：填充 `mainLootClaims / 10`（≥10 视觉封顶 100%），条上写 `本章战利品 n/10`，满 10 写 `战利品 10/10 · 下一条Boss`。主动重抽叫 **探索**（消耗金币，一次刷新两板可刷新格；地牢页不探索，刷新行写实时「刷新倒计时: HH:MM:SS」，倒计时到 `gameDay(elapsedS)` 日切）。每种带 5 档品质 `gray / green / blue / purple / orange`（灰绿蓝紫橙）。**探索永不刷灰**（权重 0）；绿最多、蓝次之、紫少、橙很少。品质倍率写在 `QUALITY_TABLE`：绿=基准 1.0，蓝需求 1.25 / 产出 1.4，紫 1.6 / 2.0，橙 2.2 / 3.0（性价比 = 产出/需求递增）。高品质需求更高、产出更高、更赚。成交 / 敌人已领奖的格子盖章（成交 / 完成 / 已领）并换底色，主按钮不可再点。失败/拦截提示用点击附近漂字，不占死栏。

### 6.0 章节与本章 Boss

- 存档：`mainChapter` 从 1 起；`mainLootClaims` 计**成功领取敌人格战利品**的次数（0 起）。战败后再增援 / 未领不 +1。旧档缺字段 hydrate 成第 1 章、计数 0。
- 本章普通敌人走杂兵 / 精英池（橙档品质不再单独当首领）。`mainLootClaims` 到 **10** 后，**探索必出本章 Boss**（不把第 10 次领取的那张单改成 Boss，也不再等加权碰巧掷出敌人）。空位补板、探索替换可刷新格，都先落这只 Boss。领满 10 次后若板上有已领敌人格 / 已完成交易格，会立刻回收一格刷出 Boss，免得格子满、只刷交易单时永远轮不到。本章 Boss 品质至少橙色：生成时若掷到橙以下则抬到橙，橙及以上按原品质表保留；旧档低于橙的本章 Boss 在 hydrate / 确保时同样抬到橙。
- 场上同一时间最多 **1** 只本章 Boss。一旦刷出（待战 / 战斗中 / 可领奖），探索与补板都不得清掉它，也不得再刷第二只。已领奖的本章 Boss 不再占这个名额。
- 领取本章 Boss 战利品后：`mainChapter + 1`、`mainLootClaims = 0`，**场上其它订单保持不动**，不 `resize` / 清板 / 强制重刷非 Boss 单。新章再重新累计战利品，满 10 再出下一章 Boss。
- 敌人三围是单一战斗底版 × 品质倍率 × 阶级倍率 × `MAIN_CHAPTER_COMBAT_MUL`（HP / ATK，约每章 +8%）。品质代表强弱；时长由 HP / ATK / SPD / 超时 / 章节倍率决定，不再有近远 / 强弱。

### 6.1 探索

`EXPLORE_COST_TABLE` 表驱动：`[8, 10, 12, 14, 16]`，按 `exploreCount` 取档，超出末档钉在 16；点亮「急单优先」后再 ×0.8（`exploreCostMul`），再点「探路折扣」叠乘 ×0.9，下限 0.6。金币不够不能探索，不换板。成功则扣金、`exploreCount++`，两板各自补到当前科技格数：战场只掷敌人（品质权重，每张新敌人格 1 条词缀），商场只掷交易种类（`MARKET_KIND_WEIGHTS`，无词缀），**只替换可刷新格**；保留格占原位。商场新刷约 30% 成限时单（点亮「双轨急单」后再 +15%；不消耗 `rngState`，用订单 id 哈希），时限按品质 15/10/5 分钟（绿灰 / 蓝 / 紫橙），第 6 章起再降一档；点亮「限时加急章」后时限 ×1.5；卡面简/详都写 `限时 MM:SS · 奖励×2`。限时内成交金币或钻石 ×2，物品获得也 ×2（消耗不加倍，工匠产量 buff 不加倍）。超时从该格拿掉留空，等下次探索补，不再额外惩罚。限时只在商场，不进探索保护。`mainLootClaims ≥ 10` 且战场没有未领本章 Boss 时，**战场第一格新刷强制本章 Boss**。交战中 / 待领胜 / 战败未清 / 未领本章 Boss 可暂超过战场目标格数（可超过 4，以免抹掉进行中的战斗）。地牢不走这套探索保留：到刷新时间仍强制刷新，可清掉进行中或战败的地牢战。

敌人格：

- **保留不刷新**：交战中、待领胜、战败未清（同一张单再增援，不刷掉），以及未领的本章 Boss（含待战）。
- **可以刷新替换**：未开打的普通敌人，以及战利品已领取。

交易格（黑心商人 / 路人 / 当铺 / 工匠委托 / 收购）：未完成与已完成都可刷新。当前没有未结清的跨格交易。

### 6.2 敌人

新刷出的交物单只要求 **1 种物品**。消耗数量表驱动：

```
qty = max(1, round(base × QUALITY_TABLE.demandMul × chapterNeedMul(chapter) × bossMul))
chapterNeedMul(chapter) = 1 + (chapter - 1) * 0.15
```

`base` 绿档第 1 章约 2，可按物品微调（`MAIN_NEED_BASE`）。物品从已解锁工位产物池 `mainNeedItemPool` 掷 1 个，跟同一套骑士开站表，不跟章节号：骑士 1 开采药与炼金，池里就有草/香料，以及 7 种药剂 id 与通配 `anyPotion`（不要裸 `potion`）；5 开狩猎后加上肉/鱼/牙/血/眼/杂物；6 开烹饪后加上熟食/烤肉/香料炖；9 开采矿后加上矿石（不要荒晶）；10 开铭刻后加上 6 种符文与通配 `anyRune`。药类 / 符类订单约 35%～40% 为通配，交单扣库存最多的那一种。第 8 章但采矿未开也不会要矿。掷到旧 `tool` / `*ToolNN` 时改从 `MAIN_NEED_TOOL_POOL`（`RUNE_ITEM_IDS`）抽一种符文。掷到 `potion` 标记（池已含药剂时）仍 resolve 成 7 种之一，再按通配权重可能改成任意药剂。新刷不再要 `tool` / `ironTool` / `mithrilTool`。战场补给与商场交物 wants（路人 / 当铺 / 委托 / 收购）共用这套挑选；表内第一种若已在当前池则保留并 resolve 标记（具体药/符再掷通配），否则改从当前池抽。商场第 0 格开局「铜矿当」是特例，采矿未开（要骑士 9）仍固定 `ore` ×2。黑心商人买货 / 路人换得物不按当前池改写。本章 Boss **只再 × `CHAPTER_BOSS_NEED_MUL`（1.25）加数量**，不再叠第二种物品。战利品绿档基准 `LOOT_GOLD_BASE = 6`，再乘 `chapterLootMul = 1 + (章-1)×0.075`（需求随章仍 ×0.15，金打半折跟），先算出金币额再掷货币种类：一单只发金币或钻石。战场杂兵偏金币（出钻率 28%）、精英各半、首领必钻石；商场当铺 / 收购偏金币，工匠委托偏钻石（另保留产量 buff）；开局铜矿当固定金币。钻石额约为该金币额的 1/5～1/10。金币单仍写 `lootGold` / `rewardGold`，钻石单对应字段为 0 并写 `lootDiamonds` / `rewardDiamonds`。旧单缺钻石字段仍按原金币发。金币单点亮「战利品分拣」后再 ×1.15；钻石单不叠这个乘区。章节需求倍率单独函数，不绑战斗 HP 倍率。旧档 `distance` / `power` hydrate 时读完即丢；已有 needs / loot 大体原样留下（进行中或超时后可再开的多物品敌不改写），其中残留的 `tool` / `ironTool` / `mithrilTool` / `*ToolNN` / 裸 `potion` 会 remap 成符文 / `salve`。库存旧工具读档转荒晶。

流程（行军门闩已换成战斗；交易单不动）：

1. 对照物资看补给；缺的标红。货不够不能开战，**不扣货**。消耗不足时，开战 / 交付 / 交易等主按钮置灰，点击漂「物资不足」；物资够则恢复可点。交战中的增援与战败后再增援都不消耗补给，不受此灰态限制。
2. 点订单卡「开战」弹框（只开选人，不算引导第 4 步）：列出休息工人（`assignment===null`、不在战斗中）；可选 **1～3** 人，不必凑满。出战 / 增援必须**满血**：`workerWearHp = hp - fatigueDebt` 到 `hpMax`（与工坊页底色血条铺满同一套）。未满血 / 有未入账劳损仍出现在列表里，但灰显；选人行**不渲染 HP 条 / HP 数字 / 「未满血」文案**，hint 只写「未达出战条件的灰显」。显示名只取**本名**（如「铁钉」），剥掉职业后缀（游民 / 骑士等）。每人右侧 **1 个空符文槽**；铭刻未按骑士开站表解锁时槽置灰，点不弹选符文层、漂「铭刻需骑士等级 N 解锁」（N 取 `STATION_UNLOCK_KNIGHT.inscription`）；解锁后点槽出第二层弹层，列全部符文种类 + 库存 + 短效果，点一种装备（可改空槽）。助战同一套 1 槽。点「邀请」后才在列表最上方加入 1 名临时助战（绿底「助战」标签，一眼能和自家工人区分），再邀替换这一个；品质/等级随机且不超过当前工人最高档与最高级，不入花名册与存档，关弹框或开战结束清掉，不领持久 XP。点亮「助战号角」后品质下限 = `max(1, floor(自身最高品质 / 2))`。弹框无取消，点遮罩可关。品质只写在工人**名字字色**（`WORKER_QUALITY_TABLE.color`，白档等浅色用偏深棕）和角标上，列表项不再套品质色边 / 左侧色条 / 粉彩底；选中单独金底金边，与品质字色无关。克制属性图标放在助战标签与名字之间（自家工人同样挨着名字，不另起一行垫底），并列 `LvN`，不写 ATK / SPD / HP。命中当前已揭示弱点 1 条标「推荐」、2 条标「强烈推荐」，0 条不标。弹框只负责选人 + 装符文。工坊页名册改成按品质分组的小图标网格，点开底部详情。
3. 弹层点「开战」确认入战：扣光该格一整套补给，并消耗已装备符文（缺货失败不扣），`departCount++`、写 `lastDepartAt`，写入 `combat`（`fighter.runeId` / `runeLoadout`）。**当时不发金币。** 出战不算派驻工坊。引导第 4 步只在这里完成，不要求打完。战斗中场上存活不满 3 人时可点「增援」：同样只选满血休息工人（不能选已在场上的；未达条件灰显），**不扣补给**但扣该人符文，加入当前场，不重置敌血与超时。战败（`outcome===lose`）后订单卡不再显示「开战」，只显示「增援」；选人弹层用增援文案，确认后在同一张订单重新开战，不扣补给，敌回满血。开过战斗（有 `combat` 或已出发）的订单永久不再显示「开战」。交战中仍是双剑小图标，有空位才另出「增援」。符文效果只打携带者、只本场：锋锐造成 ×1.25、厚甲受伤 ×0.75、迅击间隔 ×0.85、破障弱点额外 −1 盾、洞悉开战多揭示 1 条（多名只一次）、血酬战后该人 +8 战斗 XP（胜负都发）。战后清槽。地牢选人同一套 1 槽。
4. 双方三围 HP / ATK / SPD（SPD = 每隔多少秒出手）。内部结算仍用间隔秒。工人详情仍写出手间隔秒（如 `3s`、`10s`）；战场与地牢卡面敌我行不写 ATK / 攻速，改在血条下用细出手蓄力条（周期 `max(1, spd) × 1000` 毫秒，按 `nextActAt` 填充，满条为出手瞬间，出手后清空重蓄；敌人硬直时该条变灰，填充公式不变）。工人：`WORKER_COMBAT_BY_TIER` 品质底版 + `CLASS_COMBAT_MOD` 小修正，再叠战斗等级（见 2.2；本档生产表不动），再叠战斗科技（木桩加训 ATK +10%、护腕束紧 HP +10%、急行整队攻击间隔 ×0.9），再按工人 id 哈希叠一层稳定的出手间隔抖动（约 ±8%～12%，夹到 1～12s，重载不改、升级仍用同一乘区），工人详情显示抖动后的实际间隔；战场与地牢卡面用蓄力条，不写间隔文字。敌人：`ENEMY_COMBAT_BASE`（单一底版）× `ENEMY_COMBAT_QUALITY_MUL` × `ENEMY_COMBAT_RANK_MUL` × 章节倍率（HP / ATK；阶级同时拉长出手间隔）× **全阶共用** `ENEMY_COMBAT_POWER_MUL`（ATK ×1.35、出手间隔 ×0.65，小兵/精英/Boss 同一处改），最后把出手间隔夹到 **10～30 秒**。墙钟目标（两名约 5 档工人，合计约 240 伤/分）：无弱点时杂兵约 10 分钟可斩杀、精英约 12～15 分钟、首领通常战败（打死或超时）；命中弱点（×1.2～×1.5，札记再 +10%）后杂兵约 6～8 分钟、首领约 20 分钟。敌人更快更疼后出战更吃集火，先倒下会拉长战斗，可再增援。开战当下敌人先打一记，再进入正常间隔。
5. 时间轴出手，走同一套 `applyTick` / 墙钟（在线离线相同）。多工人共砍一敌。敌人攻击目标池 = **本场出战工人 + 当前工坊在岗工人**；休息中不进池。选目标表驱动（`src/sim/combatTarget.ts`）：`all` 全体；`rand1` / `rand2` / `rand3` 随机 N（池不足则全打）；`lowestHp` 血量比例最低 1 人；`highestHp` 当前血量最高 1 人；`workshopBias` 优先全体在岗、没有才打出战；`frontlineBias` 优先全体出战、没有才扫工坊；`sameStation` 先随机 1 个在岗再打同站另一人（若有）；`cleave2` 1 主目标（最低血比例）+ 1 随机。每次出手按阶级权重抽规则（小兵偏 `rand1` / `frontlineBias`，精英偏 `rand2` / `cleave2` / `lowestHp`，Boss 主残血/随机、偶发 `all` / `workshopBias`）；橙品质额外给 `all` +1 权。订单可钉 `targetRuleId`，旧档缺字段开战现抽。出战走现有战斗结算（可打死）；工坊在岗扣同一 `hp`、锁 1，进入/处于残血（hp/hpMax ≤30%）则复用自动吃食。超时按阶：`COMBAT_TIMEOUT_BY_RANK` 杂兵 / 精英 900 秒（15 分钟），首领 1800 秒（30 分钟）；`COMBAT_TIMEOUT_S` = 1800。胜负时刻记最后一次出手，而不是本次 tick 的 `now`。打死敌人判胜；场上全灭不判负（倒下回休息，可增援），只超时判负；工坊锁 1 不单独判负。
6. 敌人另有表驱动弱点（杂兵 2～3，精英 / 首领 3～4；灰绿蓝=杂兵，紫橙=精英；本章 Boss 单独强制首领，橙不自动当首领）。阶级同时改战斗倍率与超时。卡面弱点行只读该单战斗态 `weaknesses` / `revealedWeaknesses`（开战不另掷一份；生成订单或 hydrate 旧档时按阶级写入初始暴露，不重掷已有弱点表）。元素图标按属性分色（火红、冰蓝），避免火被看成水滴。开战前卡面预暴露：杂兵 2、精英 1、首领 0（全 `?`）；点亮「揭秘眼力」后小兵 / 精英再多露 1 条（不超过弱点总数，首领不加）。工人出手打中尚未暴露的弱点仍揭示并保留。未命中伤害 ×1、不揭示。命中 1 条 ×1.2，命中 2 条 ×1.5；点亮「弱点札记」后再 +0.10。只按出手工人自己的属性计，两人属性不合并。同一单交战中增援 / 战败后再增援仍保留 `revealedWeaknesses`；换新敌 / 刷掉本单清空。开战另掷破防盾（杂兵 2～3、精英 4～5、首领 6～8）；工人一击里命中几种不同弱点就扣几盾（未揭示的先揭再扣，同一击生效）。盾到 0：漂「破防！」、硬直杂兵 3 秒 / 精英 4 秒 / 首领 5 秒，硬直中受伤 ×1.5 且敌人不出手。硬直结束盾回到开战掷出的上限，清硬直与易伤。旧档进行中战斗缺盾字段时开战 / 步进 / hydrate 补掷。
7. 敌人格卡头不写类型字「敌人」（不展示 `kindTitle` / `ENCOUNTER_KIND_LABEL.enemy`）；保留品质角标、订单名字，以及杂兵 / 精英 / 首领或地牢标签；词条芯片并进同一行 tags，不另占一行。商场等其它种类仍写中文类型名。卡面显示敌我血条、弱点行小图标（未揭示仍 `?`），弱点旁写剩余盾数（硬直中改「破防中」并加卡面硬直态：头像描边、半透明罩、血条描边与脉冲）。不渲染 `statusText` 绿字行（待战 / 战斗中 / 胜可领 / 战败 / 已领都不出绿字）；按钮灰态、红色已领章保留。战斗中不再显示「开战」，也不出禁用的「战斗中…」字钮，改为不可点的双剑交击小图标（约卡头标签高，轻微颤动并脉冲，`aria-label`「交战中」）。场上不满 3 人时另出「增援」。战败不显示「开战」，只显示「增援」。友方 HP 与工坊页同一套草绿 `hpBar`：条内居中 `HP: {hp}/{hpMax}`。敌方同一套 HP 数据与受击横晃（`shake-key`），换皮为深紫/暗红填充、尖角与双层描边（`variant="enemy"`）。条外只写名字（敌方写「敌」），不写 ATK / 攻速。战斗中血条下各一条细出手蓄力。友方栏只渲染 `combatRosterFighters`（HP>0），倒下立刻消失、不留空位。工人命中已揭示弱点（暴击 / 扣盾）时敌血条短横晃约 0.26s，与卡面暴击漂字同步。敌人出手打出战工人时立刻把伤害写回 `save.workers[].hp`，打在岗则当场扣同一 `hp`（锁 1）；工坊页底色血条战斗进行中实时跟着掉；战斗结束 `writeBack` 仍会再写出战名单。出手 / 揭示弱点 / 破防 / 胜负走该订单卡本地漂字（同工坊站卡 `stationTips`：按遇敌 id 叠条上浮淡出，只在主线页渲染），不拉长卡内战报列表。命中弱点的漂字写属性中文名加「暴击」（一条 `枪 暴击`，两条 `枪 火 暴击`），不写「弱点×」；未命中仍只漂伤害；打到工坊在岗时短漂带「工坊」。`combat.logs` 仍写入存档给逻辑用。选人弹框：品质看名字字色 + 角标，选中金高亮，并列本名 / `LvN` / 属性图标 / 1 符文槽，不写 ATK / SPD / HP；命中当前已揭示弱点 1 条标「推荐」、2 条标「强烈推荐」，0 条不标。订单卡「消耗 / 获得」各写一行（敌人：消耗 `needs`，获得 `金币 ×N` 或 `钻石 ×N` 并注明战斗后领），不再写成「A → B」。消耗行写 `物品名 ×消耗 / 拥有`（例：`铁矿 ×3 / 12`），不足用弱提示色并轻微闪烁（约 1.25s，减少动效时关掉）；获得行仍分行。可生产物资可点，切到底栏工坊并选中 `itemProducerStation` 主产站；金币与产量 Buff 不可点。战场敌人格另有 1 条词缀（与地牢共用词缀池），卡面可点看完整效果；商场单无词缀。探索刷新该格时重掷词缀；旧档缺字段且非进行中战斗时 hydrate 补 1 条。
8. 胜：点「战利品」领本单金币或钻石（金币单点亮「战利品分拣」后再 ×1.15），不加物资，并给本场参战名单发 XP（成功消息可带「工人获得经验」；某人因此升级则另漂「{短名} 升至 Lv{N}」并短暂闪该人槽位）。场上工人 HP 到 0：立刻离场回休息，订单卡友方栏马上拿掉该人（不留 0 血条 / 空壳 / 灰位），战斗不因此判负；回满血（同样看劳损底色）后可再增援同一场。战场与地牢同一套。超时判败：不发金、不发 XP；已离场或仍在场的工人带伤回休息。超时战败后可再点「增援」（不再回到「开战」文案）在同一张订单重新开战：选人弹层用增援文案，不扣补给，敌回满血，只选满血 1～3 人。已取消残血再战与「再战补给」。胜负结算写回后：若该工人残血（`hp/hpMax ≤30%`）且 `foodSlot.qty>=1`，自动吃 1 回血；倒地离场时同样检查一次。
9. 仅休息回血：`assignment===null` 且不在战斗 → 每 10 秒先清劳损再加 `max(1, floor(hpMax*0.05))` HP，至有效 HP 到 `hpMax`（`applyRestHeal`）。派站不回血。战斗中工人即使 HP 已写回名册也不回血。药剂走工坊页 4 槽点用（全体规则目标，无单人点选；点？看效果）。

`marchEndsAt` 不再驱动主流程。旧档已出发且仍有行军墙钟、未领奖 → hydrate 成胜可领。旧档已 `departed` 且没有 `marchEndsAt`（当时已发过补给金）→ `lootClaimed`。旧档已扣货未开战（`submitted`）→ 开战免再扣。

### 6.3 黑心商人 / 路人 / 当铺 / 工匠委托 / 收购

五种交易互斥，卡面标题用中文名，只渲染该类型允许的按钮。品质与章节已在生成时写入需求 / 产出。玩家交物侧（敌人 needs、委托 / 收购 / 路人 wants、当铺 pawnWants）以及黑心商人 buyOffers 都只写 1 种物品；路人 offers 仍可以是另一种。卡面同样分行：黑心商人消耗金币、获得物资；路人消耗 wants、获得 offers；当铺消耗 pawnWants、获得金币；工匠委托消耗 wants、获得产量 Buff（新单另可能带金币或钻石，偏钻石）；收购消耗 wants、获得金币或钻石（偏金币）。

1. **黑心商人**（kind `blackMerchant`）
   - 只提供：玩家花金币购买对方货物
   - 不以物易物、不以物换钱
2. **路人**（kind `passerby`）
   - 只提供：以物易物
   - 不收金币买、不以物换钱
3. **当铺**（kind `pawn`）
   - 只提供：以物换钱（交出列出的物资，按价表换金币或钻石，偏金币；开局铜矿当固定金币）
   - 报价表驱动：`pawnUnitGold = max(1, floor(sellGold * PAWN_RATE))`，`PAWN_RATE = 0.75`，略低于 `sellGold`；品质再乘产出倍率；点亮「议价铜铃」后当铺 / 收购实发金币再 ×1.15（生成时的 `rewardGold` 仍是金币底价）
   - 列出可典当物品与报价，确认后扣货加金币或钻石；货不够失败、不扣错货
   - 不购买、不以物易物
4. **工匠委托**（kind `artisan`）
   - 提交指定成品，给工坊临时产量 buff；新单另掷金币或钻石（偏钻石），不奖物资（配方系统未就绪，先不做限时配方）
   - buff 写入 `workshopBuff`，站点速度乘 `buffMul`，到期失效；卡面「获得」写货币（若有）与产量时长
5. **收购**（kind `bulkBuy`）
   - 高价收指定成品：玩家给物品换金币或钻石（偏金币）
   - `bulkUnitGold` 用 `BULK_BUY_RATE = 1.15`，单价优于当铺

成交后该格 `completed`（敌人领奖后 `lootClaimed`）。卡面不再出「这笔买卖已成交 / 委托已完成 / 这笔收购已成交」绿字，只留按钮灰态（成交 / 完成）与红色盖章。货不够 / 金币不够则失败。物资装得下任意换得货物，不再因「满」失败。

旧存档 `kind: 'shady'` / `'pawnshop'` 迁成 `blackMerchant` / `pawn`；通用 `kind: 'merchant'`：有收购+换得字段则迁成路人；只有金币购买则迁成黑心商人；否则默认路人。缺品质的旧格补 `green`。

### 6.4 开局与旧存档

新档生成战场 2 格敌人 + 商场 2 格：商场第 0 格固定绿档当铺「铜矿当」，消耗铜矿 `ore` ×2（第 1 章特例，不跟采矿解锁走），奖励按 `pawnUnitGold` / `rewardGold`，不掷限时；第 1 格走普通商场池（可限时）。探索可刷掉铜矿当。章节 1、战利品计数 0。战场新敌补给只抽草/香料。空双板 hydrate 同样补铜矿当到商场并扩到当前格数；旧档已有板不强制插入铜矿当，但格数不足 `marketSlotCount`（含新下限 2）时轻扩。旧混合单板 hydrate：敌人进战场（交战中 / 待领胜 / 战败未清优先留下，可暂超 2 格）、交易进商场，再按 `battlefieldSlotCount` / `marketSlotCount` 轻扩轻收。旧存档若仍是单格出发（`currentOrderId` / `orderIndex` / `orderSubmitted`），把旧需求迁进战场第 0 格敌人（旧档已扣货则内部记一笔，开战不再扣）。

### 6.5 地牢（每日 2 单）

独立战斗，不占战场格、探索不刷新（地牢页不放探索钮，刷新行写「刷新倒计时: HH:MM:SS」，按 `gameDay(elapsedS)` 日切剩余秒，每 tick 更新）。到刷新时间仍强制刷新两单，可清掉进行中或战败的地牢战；这与战场探索保留交战中 / 待领胜 / 战败未清单分开。地牢页两列并排两张卡。存档 `dungeon.encounters` 固定 2 张，`attemptsUsedById` 按单计数。每单各掷 **2** 个不重复词缀（厚皮 / 迅捷 / 重击 / 铁盾 / 尖刺 / 富矿 / 急醒 / 砸场强化 / 迟援 / 钝刃），写在该卡头 tags，点词缀出气泡看完整效果。不再有顶栏「今日词缀」，也不再存全局 `affixIds`。词缀幅度：厚皮 ×1.4、迅捷间隔 ×0.7、重击 ×1.45、铁盾 +2、尖刺 +4、富矿把**本单货币** ×1.5、急醒（破防硬直 −1s）、砸场强化（工坊伤害 ×1.5）、迟援（增援延迟 4s 出手）、钝刃（克制倍率固定 ×1）。战斗结算只读本单 `affixIds`。每单每天 1 次开战（共 2）。开战各扣一套苛刻补给（草 ×12、香料 ×6、熟食 ×4、回春散 `salve` ×3，两单共用这张表）并消耗该单次数；超时 / 战败不退次数。增援不耗次数、不扣补给。场上最多 **5** 人，满血才能进场 / 增援。开战、增援、领宝箱都带 encounter id。

两只 Boss 共用当日 `dungeon.chapter`，阶段表各一套，不要克隆。**深渊狱卒** `dungeonJailer`（钻单）：生命 9600、攻击 6、出手间隔 5s，阶段盾 **7 → 9 → 12**，机制偏砸场，目标偏工坊；基准另有工坊伤害 ×1.25、增援延迟 2s（词缀迟援仍取 4s 的更大值）。**黑市掮客** `dungeonBroker`（金单）：生命 6200、攻击 7、出手间隔 3s，阶段盾 **4 → 6 → 8**，机制偏横扫，后两段目标偏残血；基准另有打场上工人 +3、克制加成只留 35%。破防硬直 **3s**（急醒 −1s）。铁盾词缀给本单每阶段盾 +2。**日切刷新**时按当时 `mainChapter` 写入 `dungeon.chapter` 并表驱动缩放（约每章 HP ×1.12、间隔 ×0.97、攻击 ×1.06，第 3 章起盾基线 +1）；当日两单锁这一章，主线中途进章不重算。破完一阶段进下一阶段并换该 Boss 的弱点与机制。选目标规则在阶段切换与约 18s 计时器上轮转（横扫、工坊、同站、随机 2、残血）。未进第 3 阶段前 Boss 生命锁 1，必须破完阶段才能斩杀。

结束领「宝箱」：铜 / 银 / 金按最高阶段与是否通关（通关金箱）。钻单发钻石（铜 12 / 银 22 / 金 40）和较少的草/熟食/回春散，`lootGold=0`。金单发金币（铜 40 / 银 70 / 金 100，金箱随章节每章约 +8%），`lootDiamonds=0`。富矿只抬本单货币。通关才发工人战斗 XP，两单各自通关各发。游戏日切**强制刷新**：两场战斗中先日切判败，未领宝箱先自动入库，再按当前章节锁两张新单、各换 2 条词缀、次数回到 0、阶段清空。旧档缺 `dungeon` hydrate 补当天两单；旧的单场 `encounter` + 全局词缀摊到两单（进行中的战斗留在狱卒单，除非本来就是掮客）；已有地牢缺 `chapter` 的锁 1，不拿实时章节重算。周常换皮 / 排行 / 主将技不做。

## 7. 日循环与离线

- 1 tick = 1 秒。
- 1 游戏日 = 1440 秒（24 分钟现实时间）。只做显示，不改公式。
- 在线每秒 `applyTick` 一次；离线按秒数连跑同一个 `applyTick`。
- 离线上限默认 **8 小时**（`OFFLINE_CAP_S = 28800`）。点亮「夜班油灯」后再 +2 小时；再点「长夜油灯」再到 12 小时。超过的部分丢掉。
- `settleOffline` 对比结算前后物资 / 站点 / 金币，生成摘要。boot 与 `visibilitychange` 回前台时 catch-up。有变化时写入一条未读「离线收益」消息（时长、主要产出等），**不再强弹顶栏大摘要条**。顶栏「消息」按钮有未读红点。

`localStorage` 键名：`idea5Idle`。整份 `Save` JSON。

科技树见 `src/sim/tech.ts` 的 `TECH_TABS`：三页签 `production` / `combat` / `affairs`（生产 / 战斗 / 事务）各自独立线性层。每层 2～3 个选项、同行同价；**每个节点都可配置 `maxLevel` 并记存档 `techLevels`**，未满级可对同一节点再点（每层同行同价，扣 1 次灵感）。该层任意节点 `level≥1` 即解锁上一层（或本层已有旧档点亮则可补买同行），无互斥加价，最终都能买齐。层自下而上排：第 1 层在屏幕最下。共用 `techPoints` 灵感。图标叠 `level/maxLevel`（未买 `0/N`，点满用已激活样式且不可再点）。
