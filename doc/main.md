# 车间闲置 · 主体

纯前端挂机。定位：**抽工人、排流水线、同站堆人加速**。第一期纯生活；偶遇敌人「出发」只做补给门闩，真战斗后做。

工程对齐同作者 idea3_hospital：Vue3 + TypeScript + Vite + Pinia + Vitest，`src/sim` 纯逻辑，`src/ui` 薄门面，在线与离线都走同一个 `applyTick`。不复制医院的房间 / 污染 / 病人。GitHub Pages 为 project site，Vite `base` 为 `/idea5_idle/`，在线地址 https://sung1011.github.io/idea5_idle/ ，推 `main` 即部署。

另见：[分阶段落地](todo.md)、[站点等级与品类](stationProgress.md)

主界面拆成页签（无路由库）：**车间**（站点派遣 / 进度 / 品类）、**银行**（缓冲库存与每物品进度条）、**工人**（抽人 / 名册 / 派遣）、**偶遇**（5 格遭遇、探索、敌人补给 / 出发、商人换货 / 购买）。摘要条、离线提示、堵点 / 共振仍在顶栏，各页签都能看见。移动端页签可点。

---

## 1. 定位

一存档是一个账号：共用银行（站间缓冲）、工人名册、统一时钟。金币只服务生活（抽人 / 探索 / 商人购买消耗，卖货 / 出发补给金），不接战斗。

- **Worker**：抽取获得。可保留 `classId` 占位，第一期不当战斗成长用。
- **生活站点**：伐木、采矿、炼金、钓鱼、烹饪、锻造（武器）。各站独立玩法 + 挂机，经银行连成流水线。
- 武器是制品：交给偶遇敌人当补给、收藏或卖钱，不武装战斗。

三条主轴：

1. **跨站流水线**：采矿 → 铜/铁/秘银矿缓冲 → 锻造对应兵器入库；钓鱼 → 鱼缓冲 → 烹饪；伐木弱接炼金；炼金渣滓可回流铜器锻造。
2. **同站堆人加速（迅雷手感）**：同一站点可派多个 worker，人越多该站进度 / 吞吐越快。
3. **车间共振**：相邻站同时有人 → 下游少空转、额外产出 / 图纸。
4. **堵点可见**：缓冲见底 / 堆满提示。

## 2. 对象

### 2.1 账号

| 字段 | 含义 |
| --- | --- |
| `gold` | 金币。抽人 / 探索 / 商人购买扣金，卖货 / 出发补给金加金。不学战斗技能。 |
| `bank` | 站间缓冲。铜/铁/秘银矿、鱼、木头、渣滓、铜/铁/秘银器等堆叠，带容量。 |
| `workers` | 工人名册。 |
| `stations` | 各站进度 / 空转原因 / 完成次数 / 独立等级与 XP / 当前品类。进度在站点上，不在工人身上。 |
| `lastTick` | 上次 tick 墙钟，离线追赶用。 |
| `elapsedS` | 累计游戏秒。 |
| `encounters` | 偶遇板，固定 5 格。每格是敌人或商人。 |
| `exploreCount` | 成功探索次数，驱动探索费用与下一板种子。 |
| `departCount` | 成功出发次数。 |
| `lastDepartAt` | 上次出发墙钟；没有出发过为 `null`。 |

### 2.2 Worker

```ts
Worker = {
  id,
  name?,
  classId?,          // 占位，第一期不读成长
  assignment: stationId | null,
}
```

同一 worker 同时只能派一个站。多个 worker 可以派到同一站。

### 2.3 站点

| 站点 | 循环（默认档） | 消耗 | 产出 | 相邻（共振） |
| --- | --- | --- | --- | --- |
| 采矿 | 5s（铜矿） | — | 铜矿 `ore`；Lv5 铁矿；Lv10 秘银矿 | 锻造 |
| 锻造 | 8s（铜器） | 表驱动 `costs`：铜器 `[{ ore, 1 }]`（没有矿则 `altCosts` 渣滓）；铁器 `[{ ironOre, 1 }, { wood, 1 }]`；秘银器 `[{ mithrilOre, 1 }, { wood, 2 }]` | 铜器 `weapon`；Lv5 铁器；Lv10 秘银器 | 采矿、炼金 |
| 钓鱼 | 6s | — | 鱼 | 烹饪 |
| 烹饪 | 7s | 鱼 | 熟食 | 钓鱼 |
| 伐木 | 5s | — | 木头 | 炼金 |
| 炼金 | 10s | 木头 | 药剂 + 渣滓 | 锻造、伐木 |

本阶段 UI 主玩：采矿 / 锻造、钓鱼 / 烹饪、伐木。炼金仍是表 + 同一套 tick 骨架，可派但不当主界面。

采矿 / 锻造各站独立等级与 XP，开局只解锁第 1 品类；每 5 级解锁下一档。高阶是新物品，不是换皮。整站只选一个品类，堆人加速当前档。钓鱼 / 烹饪 / 伐木第一期仍单一品类。细则见 [stationProgress.md](stationProgress.md)。

伐木产木头进银行，可单件卖出。高阶锻造弱接木头：铁器 / 秘银器 `costs` 带 wood（铜器基础链不耗木，避免开局卡死）。炼金耗木出药剂。原料不足则空转并提示缺哪几样，够则一次性扣光 `costs` 再产出。

偶遇敌人第一期仍收基础铜器 `weapon` / 熟食 / 矿与干粮；高阶铁器需求后做。

## 3. 同站堆人加速

进度记在站点。每秒：

```
stackFactor(n) = n
speed = (1 / cycleS) * stackFactor(n) * (共振 ? 1.2 : 1)
progress += speed
progress >= 1 → 完成一次吞吐，progress -= 1
```

例：采矿 `cycleS = 5`

- 1 人：`speed = 0.2/s`，5 秒出 1 矿
- 3 人：`speed = 0.6/s`，同等时间 3 倍吞吐（约 1.67 秒出 1 矿）

`cycleS` 取当前 `selectedCategory`。没人的站不推进。原料见底（锻造高阶档缺对应矿也算）或产物堆满时进度冻结，并写 `stallReason`。

## 4. 流水线与共振

主轴：采矿把当前品类的矿推进银行 → 锻造扣对应矿出兵器；钓鱼把鱼推进银行 → 烹饪扣鱼出熟食。两条链共用 `RESONANCE_SPEED_MUL` / `RESONANCE_BONUS_EVERY`。

共振：`STATION_DEF.neighbors` 两端同时有人。

- 双方速度 × 1.2（下游少空转）
- 共振期间每完成 4 次吞吐，主产物额外 +1；锻造额外再掉 1 张图纸

配方 `costs`：`IoRule[]`，三种形态同一套结算。

1. 单料 1 个：`[{ itemId: 'ore', qty: 1 }]`
2. 同料 n 个：`[{ itemId: 'ore', qty: n }]`
3. 多料：`[{ itemId: 'ore', qty: n }, { itemId: 'wood', qty: m }]`

`takeCosts` 先看齐再扣；缺任一原料整单不扣，提示列出缺的物品。铜器另有 `altCosts`（渣滓）。

堵点：

- 当前锻造品类 `costs` 见底 → 锻造空转（铜器档仍可用渣滓；铁/秘银缺矿或木头都会空转）
- 当前采矿品类产物堆满（铜/铁矿容量 200，秘银矿 160）→ 采矿停工
- 鱼见底 → 烹饪空转；鱼堆满（容量 200）→ 钓鱼停工
- 木头同理（伐木堆满；铁/秘银锻造也会因缺木空转）

银行页每个物品显示 `数量/cap` 进度条：≥80% 警告色，100% 满仓。堵点「堆满」与该 cap 一致。各物品 cap 相对初版表 ×10（铜/铁矿 200，秘银矿 160，鱼 200，木头 300，铜器 500，铁器 400，秘银器 300，熟食/药剂 400，渣滓/图纸 200）。

## 5. 抽人

表驱动。扣 `RECRUIT_COST`（15）金币，按 `WORKER_NAME_POOL` / `CLASS_PLACEHOLDERS` 轮转写花名册。金币不够失败，不写工人。

卖货：银行可单件卖出；「卖货」把武器和熟食整批换成金币。流水线制品的主去处是偶遇敌人补给（见第 6 节）；卖货仍可用，但是另一条出路。

## 6. 偶遇（探索 + 敌人门闩 + 商人，不是战斗）

偶遇板固定 **5 格**，同时最多展示 5 个遭遇。页签 / 面板标题用「偶遇」。主动重抽整板叫 **探索**（消耗金币）。

### 6.1 探索

`EXPLORE_COST_TABLE` 表驱动：`[8, 10, 12, 14, 16]`，按 `exploreCount` 取档，超出末档钉在 16。金币不够不能探索，不换板。成功则扣金、`exploreCount++`，按新种子重抽整板 5 格。

### 6.2 敌人

带远近（`distance`: 近 / 远）与强弱（`power`: 弱 / 强）。

- 远 → 更高食物 / 干粮（熟食、鱼）
- 强 → 更高矿物与武器（铜矿、铜器）

流程：

1. 对照银行看补给；缺的标红。货不够不能「提交补给」，不扣货。
2. 「提交补给」：银行够则扣货，该格 `submitted = true`。已提交不能再扣一次。
3. 「出发」：仅当该格已提交。成功则 `departCount++`、发该格表驱动补给金、写 `lastDepartAt`，该格标记 `departed`。
4. UI 文案「已出发（战斗稍后）」。**不做战斗结算、战斗循环、伤害 tick。**

### 6.3 商人

展示收购货物。玩家可：

- **以物易物**：花银行物品换对方物品
- **金币购买**：扣金币拿对方物品

成交后该格变为已完成。货不够 / 金币不够 / 银行装不下则失败，不扣错物品。

### 6.4 开局与旧存档

新档生成初始 5 格偶遇。旧存档若仍是单格出发（`currentOrderId` / `orderIndex` / `orderSubmitted`），生成 5 格并把旧需求迁进第 0 格敌人（已提交状态保留）。旧的单格出发流程已替换为偶遇板。

## 7. 日循环与离线

- 1 tick = 1 秒。
- 1 游戏日 = 1440 秒（24 分钟现实时间）。只做显示，不改公式。
- 在线每秒 `applyTick` 一次；离线按秒数连跑同一个 `applyTick`。
- 离线上限 **8 小时**（`OFFLINE_CAP_S = 28800`）。超过的部分丢掉。
- `settleOffline` 对比结算前后银行 / 站点 / 金币，生成摘要。boot 与 `visibilitychange` 回前台时 catch-up；上线 UI 显示离线多久、各站产出/消耗要点、金币变化（有则显示）。

`localStorage` 键名：`idea5Idle`。整份 `Save` JSON。
