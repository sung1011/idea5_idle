# 骑士工坊 · 主体

纯前端挂机。定位：**抽工人、排流水线、同站堆人加速**。主线敌人是补给开门闩后的时间轴战斗（HP / ATK / SPD），交易单不动。

工程对齐同作者 idea3_hospital：Vue3 + TypeScript + Vite + Pinia + Vitest，`src/sim` 纯逻辑，`src/ui` 薄门面，在线与离线都走同一个 `applyTick`。不复制医院的房间 / 污染 / 病人。GitHub Pages 为 project site，Vite `base` 为 `/idea5_idle/`，在线地址 https://sung1011.github.io/idea5_idle/ ，推 `main` 即部署。

另见：[生产定稿](production.md)、[分阶段落地](todo.md)、[站点等级与品类](stationProgress.md)。七工坊、工人双槽、钓鱼细则与明确不做以 production 为准。第 2 期已落地采集四差异；第 3 期已落地锻造软失败与工具槽；第 4 期已落地烹饪食物槽与生产 Buff；第 5 期已落地炼金占位（耗草 / 猎副产出 `potion`，效果不填）与打磨。炼金效果数值仍后补。

游戏定名 **骑士工坊**（仓库名 `idea5_idle` 可保留）。主界面按竖屏手机壳排：去掉大标题桅杆；顶栏粘性资源 HUD（金币 / 钻石 / 工人数 / 骑士等级 / 灵感芯片可横向滑，右侧消息未读红点 + 设置图标）；底栏固定四页签，图标在上、文案在下，选中金底，并吃 `env(safe-area-inset-bottom)`。页签无路由库：**工坊** / **工人** / **主线** / **科技**。不做跨站状态清单、日时钟或玩法说明。设置弹框分页：**统计**（游戏日 / 已运行 / 探索 / 出发 / 抽人 / 骑士等级 / 离线次数）、**常规**（音乐 / 音效开关，先记本地 preference）、**GM**（初始化、加资源、满品质工人，仅调试）。钻石 `diamonds` 是高级代币占位，默认 0。停产靠站点卡片红框（只剩缺料）。制造站卡片「消耗库存」只列当前这次会扣的物品（选中品类 `costs` / `altCosts`，炼金只列当前会走的那一组）；采集站无消耗则不显示该块。产出不再常驻「产出库存」，完成吞吐时带 `stationId`，只在工坊页对应站卡上漂「获得 …」（一次吞吐多种合并）；空杆 / 遇险 / 软失败无产出则漂该站 notice。切走其它页不显示这类产出漂字。金币不足等全局拦截仍用 `floatTips`。主界面不再卖货。没有银行页，也没有容量条。不存 `recentGains`。

## 1. 定位

一存档是一个账号：共用物资库存、工人名册、统一时钟。金币只服务生活（抽人 / 探索 / 黑心商人购买消耗，当铺典当 / 收购 / 敌人战利品加金），不接战斗。

- **Worker**：抽取获得。带 `qualityTier` 1～10（颜色档）与 `classId`（生活职业，战斗只做三围小修正）。同档两人可合成升一档。存 `hp` / `hpMax`；hydrate 缺则按表满血。另存战斗 `level`（从 1）与当前级内 `xp`；hydrate 缺则 Lv1、xp 0。另存 `combatAttrs`（剑枪匕首斧弓杖 / 火冰雷风光暗），槽数看品质。
- **生活站点（定稿七站）**：挖矿 `mining`、锻造 `forging`、狩猎 `hunting`、烹饪 `cooking`、采药 `herbalism`、炼金 `alchemy`、钓鱼 `fishing`。采集 / 制造各有核心差异，经同一套物资库存连成流水线。细则见 [production.md](production.md)。
- **现码已是七站骨架**：采矿、锻造（工具）、狩猎、烹饪、采药、炼金、钓鱼。伐木 `woodcutting` 废弃并藏入口；旧档已派伐木的工人 hydrate 撤到休息。
- 锻造主产物改为生产工具，进物资后再装到**工坊** `StationState.toolSlot`（工坊站卡装/卸）。该站已装工具则本站结算吃增效；没装 = 裸效率，仍可派。**武器线搁置**。工人只留 `foodSlot` 装烹饪食物，同时仅 1 个生产 Buff；到期槽内还有则自动吃 1 份刷新，可手动吃 1，可立即换食覆盖。偶遇补给收食物 / 工具 / 矿。每站最多 2 人；同站满两人可在工坊站卡合并升档。

三条主轴：

1. **跨站流水线（定稿）**：挖矿 → 矿石 → 锻造工具 → 工坊 `toolSlot`；钓鱼 / 狩猎 → 烹饪食物 → 工人 `foodSlot`；采药 / 狩猎副产 → 炼金出 `potion` 占位（第 5 期已能做，效果不填）。第 2 期采集已按节点 / 空杆 / 遇险 / 稳采结算；第 3 期工具槽已生效（现改为站装）；第 4 期食物槽续 Buff，与站上工具词条同 `effectId` 取最强；炼金解析口 `potionEffectValue` 本阶段恒为 0。
2. **同站堆人加速（迅雷手感）**：同一站点最多派 2 人。人数项仍是线性（2 人基础为 1 人的 2 倍），满 2 人再乘冲突倍率（未研究 ×0.5，工坊规章 ×0.75，工匠密录 ×1）。第 3 人派入失败。
3. **堵点可见**：原料见底提示。物资无容量，堆再多也不停产。不恢复银行容量停产。

### 2.2 Worker

工具挂在站点 `toolSlot`（工坊站卡装/卸，本站结算吃满）；第 4 期工人 `foodSlot` 续期：

```ts
Worker = {
  id,
  name?,
  classId?,          // 生活职业；战斗 = 品质底版 + 职业小修正
  qualityTier,       // 1～10；抽人默认白档 1；旧档缺字段 hydrate 补 1
  assignment: stationId | null,  // 每站最多 2 人；出战不算派驻
  foodSlot: FoodSlot | null,   // 烹饪产物；同时仅 1 个生产 Buff；到期自动吃 1 份刷新；可手动吃 1；可立即换食覆盖
  hp, hpMax,         // 战斗生命；hydrate 缺则满血
  level,             // 战斗等级，从 1；hydrate 缺则 1；抽人 / spawn 默认 1
  xp,                // 当前级内经验；仅战胜领战利品发放；hydrate 缺则 0
  combatAttrs,       // 战斗属性；白 0、绿蓝青 1、紫+ 2；同人不重复
}
```

品质 10 档写在 `WORKER_QUALITY_TABLE`，UI 用档色一眼区分。无灰；白为最低档；粉插在橙后、红前：

| 档 | id | 名 | 色 |
| --- | --- | --- | --- |
| 1 | `white` | 白 | `#c4bba8` |
| 2 | `green` | 绿 | `#3e9a2a` |
| 3 | `blue` | 蓝 | `#3a7ad9` |
| 4 | `cyan` | 青 | `#1aa6a6` |
| 5 | `purple` | 紫 | `#8a4ecf` |
| 6 | `orange` | 橙 | `#e67a12` |
| 7 | `pink` | 粉 | `#ff7aad` |
| 8 | `red` | 红 | `#d43a3a` |
| 9 | `gold` | 金 | `#d4a017` |
| 10 | `rainbow` | 彩 | `#e83e8c` |

旧档只存 `qualityTier` 数字。存档用 `workerQualityRev` 标记色表：缺字段或 `< 2` 视为旧灰表（1灰 2白 3绿 4蓝 5青 6紫 7橙 8红 9金 10彩），hydrate 按 `1→1、2→1、3→2、4→3、5→4、6→5、7→6、8→8、9→9、10→10` 迁一次后盖成 `2`。已是新表的档不再映射，避免绿被再压成白、粉被压成橙。新 7 粉无人自然拥有。

合成：只允许**同一工坊、同档**两人。入口在工坊站卡工人行右侧（满 2 人才显示）。消耗两人，产出 1 个高一档新人；满档（10）不能再升。不同档 / 不同站 / 不满 2 人失败。工人食物槽卸回物资（只退槽内剩余份）；站上工具留下。新人留在原站、空槽。站卡合成按钮固定显示「合成」。职业在「新档可用池」里用 `rngState` 随机：`minQuality ≤ 新档` 的 `classId` 都能抽到，可能是两人已有的，也可能是池里其它职业。1 档池仍是力工 / 匠人 / 游民；更高档依次解锁矿工、渔夫、猎手、厨子、药农、铁匠、炼金师、管事、骑士。名字仍按 `WORKER_NAME_POOL` 与 `nextWorkerId` 轮转。本档品质只区分外观与职业池，不改吞吐公式。战斗经验均分：`avgTotal = floor((totalXp(A) + totalXp(B)) / 2)`，新人按 `fromTotalXp(avgTotal)` 写 `level` + `xp`。战斗属性：抽人 / hydrate 只往已解锁空槽掷互不重复的 id；合成保留第一人已有属性，只补新解锁空槽。旧档缺字段按品质补；白档空数组，卡面灰字「无战斗属性」；有属性只显示 20×20 正方形小图标芯片（title/aria 仍用中文名）。

战斗等级只改三围，不改生产 / 品质。出战三围 = `WORKER_COMBAT_BY_TIER` + `CLASS_COMBAT_MOD`，再叠等级：相对 Lv1 每级 HP +4%、ATK +3%、出手间隔 ×0.99（最快不低于该底版的 70%）。`xpToNext(L) = round(20 * 1.25^(L-1))`，可连升；`totalXp` / `fromTotalXp` 供合成。升级重算 `hpMax`，当前 `hp` 按升级前比例留到新上限。XP **只**在战胜后点「战利品」时发给本场 `combat.workerIds` 里仍在名册的工人（含已写回且 HP≤0）；败战 / 未领 / 战斗中不发。发放量按阶级底值（杂兵 8 / 精英 14 / 首领 24）+ 每章 +1。`workerLiveStats` / `fillWorkerHp` / `beginEnemyCombat` 都走带等级的算法。

特效可来自该站工具或派在该站的工人食物：同 `effectId` 取最强，不同 ID 并存；炼金走同一套 `effectId` 解析口（`potionEffectValue`），本阶段恒为 0。同一 worker 同时只能派一个站。每站最多 2 人。旧档工人 `toolSlot` hydrate 时尽量迁到 match 站，装不下则回物资；同站超过 2 人的撤到休息。

### 2.3 站点

定稿七站（差异与去向见 [production.md](production.md)）：

| 站点 | `stationId` | `kind` | 核心差异 | 产出 → 去向 |
| --- | --- | --- | --- | --- |
| 挖矿 | `mining` | gather | 节点生命，挖空等恢复 | 矿石 → 锻造 |
| 锻造 | `forging` | craft | 配方 + 软失败 | 生产工具 → 工坊 `toolSlot` |
| 狩猎 | `hunting` | gather | 遇险检定（非战斗） | 肉 → 烹饪；血/牙/眼 → 炼金 |
| 烹饪 | `cooking` | craft | 产出食物 | 食物 → `foodSlot` → 生产 Buff |
| 采药 | `herbalism` | gather | 无限稳采 | 草 → 炼金；香料 → 烹饪 |
| 炼金 | `alchemy` | craft | 一次性消耗草 / 血 / 牙 / 眼（效果未定） | `potion` 占位 |
| 钓鱼 | `fishing` | gather | 可空杆；期望更慢；随机；渔场品阶墙 | 鱼 → 烹饪；杂物低权 |

**旧站**：伐木 `woodcutting` 已移出主界面与派站按钮。hydrate 把已派伐木的工人撤到休息。`wood` 旧档数量保留、可在偶遇出手，不再产出。不做制皮 `leatherworking`。

现码 UI 主玩七站，工坊页左侧七站竖签（采矿 / 锻造 / 狩猎 / 烹饪 / 采药 / 炼金 / 钓鱼，钓鱼末签），切签右侧只显示该站一张卡。竖签底色按该站显示进度自下而上浅绿/金填充（与站卡同一套 `useVisualProgress` / `station.progress`+speed；停产/冰冻偏灰并停住）；选中金边叠在进度层上。在岗每人一颗品质色点（`WORKER_QUALITY_TABLE.color`，约 7px），空岗不画点。无骨架折叠。锻造出工具（铜/铁/秘银档），可软失败；工坊站卡可装备/卸下该站工具，工人页只选食物与数量装 `foodSlot`，可手动吃 1。挖矿有节点生命，挖空后该矿恢复中可换其它已解锁矿；钓鱼按渔场掉落（可空杆、初级不出高阶）；采药无限稳采草/香料；狩猎周期结束做遇险检定（短暂停手 / 本次减产，无战斗 UI）。烹饪：烤鱼耗鱼出 `meal`，烤肉耗肉出 `roast`（开局可做），香料炖耗肉/鱼+香料出 `stew`（Lv5）。炼金耗草或猎副产（血/牙/眼）出 `potion`，不能装食物槽、不加生产 Buff。每站最多 2 人；满两人可在该站卡合并。站卡 header 只写品类与周期，不写「n/2 人」；header 下在岗工人同一行横排（0～2）：品质角标 + 品质色名字（白档深棕）+ `LvN`，满 2 人时右侧出合并；无人则一行淡字「空岗」。

采矿 / 锻造 / 钓鱼 / 狩猎 / 烹饪各站独立等级与 XP。采矿 / 锻造 / 钓鱼 / 狩猎开局只解锁第 1 品类，每 5 级解锁下一档；烹饪开局解锁烤鱼与烤肉，Lv5 解锁香料炖。高阶是新物品，不是换皮。整站只选一个品类，堆人加速当前档。采药 / 炼金仍单一品类。周期全部 ×4（不足 20s 提到 20s）。升级 `xpToNext(L) = round(100 * 1.45^(L-1) * 0.175)`，铜/铁/秘银每次 1/2/3 XP，到 Lv5 累计 133，前期升档墙钟比旧周期+旧 XP 大约快 30%。细则见 [stationProgress.md](stationProgress.md)。

原料不足则空转并提示缺哪几样，够则一次性扣光 `costs` 再产出。产出不受库存数量限制。

偶遇敌人新单改收食物 / 工具 / 矿。旧档武器需求仍可成交。

## 3. 同站堆人加速

进度记在站点。每秒：

```
stackFactor(n) = n
speed = (1 / cycleS) * stackFactor(n) * stationConflictMul
progress += speed
progress >= 1 → 完成一次吞吐，progress -= 1
```

例：采矿 `cycleS = 20`

- 1 人：无冲突，`speed = 0.05/s`，20 秒出 1 矿
- 2 人未研究：人数项 0.10/s 再 ×0.5 → 与 1 人相当
- 2 人已点「工坊规章」：×0.75；已点「工匠密录」：×1.0（消除冲突）
- 3 人：`stationSpeed` 仍按 n 倍算（玩法派驻上限 2）

`cycleS` 取当前 `selectedCategory`。没人的站不推进，且 `assignedCount <= 0` 时立刻把 `station.progress` 置 0（站卡条与左侧竖签进度底同一字段，一起归零）；再派人从 0 涨。原料见底（锻造高阶档缺对应矿也算）时进度冻结，并写 `stallReason: emptyInput`。产物再多也不停产，没有满仓。

## 4. 流水线

定稿主轴见 [production.md](production.md) 第 3～4 节。现码主轴：采矿把当前品类的矿推进物资（挖空等恢复）→ 锻造扣对应矿出工具；钓鱼按渔场随机出鱼/杂物/空杆、狩猎出肉 → 烹饪出熟食/烤肉/香料炖进 `foodSlot`；采药出草/香料、狩猎出副产 → 炼金扣草或血/牙/眼出药剂占位。相邻站同时有人不再加速、也不额外掉主产物。`STATION_DEF.neighbors` 已清空，结算不读。

配方 `costs`：`IoRule[]`，三种形态同一套结算。

1. 单料 1 个：`[{ itemId: 'ore', qty: 1 }]`
2. 同料 n 个：`[{ itemId: 'ore', qty: n }]`
3. 多料：`[{ itemId: 'ore', qty: n }, { itemId: 'wood', qty: m }]`

`takeCosts` 先看齐再扣；缺任一原料整单不扣，提示列出缺的物品。铜器另有 `altCosts`（渣滓）。

堵点（只剩缺料，没有满仓）：

- 当前锻造品类 `costs` 见底 → 锻造空转（铜档工具仍可用渣滓；铁/秘银只缺对应矿）
- 当前烹饪菜谱原料见底 → 烹饪空转（烤鱼缺鱼；烤肉缺肉；香料炖缺肉/鱼或香料）
- 草与猎副产都见底 → 炼金空转（卡面写「草 / 血 / 牙 / 眼见底」）
- 采集站不因物资数量停工

制造站卡片就近显示当前这次消耗库存；采集无消耗则不列。产出靠吞吐完成时挂在对应工坊站卡的本地「获得」漂字，不走全局居中 `floatTips`，不常驻产出列表。没有独立物资区、容量条 / 快满 / 满仓。数量可无限（仅 `MAX_SAFE_INTEGER` 软夹，防溢出，UI 不表现满）。库存仍写 `save.bank`。

## 6. 主线（章节 + 探索 + 六种订单 + 品质；敌人是战斗）

主线订单格数随科技变：**初始 1 格**，探路哨岗 / 市集执照 / 斥候驿站 / 远望烽台 / 商队路引 五道大科技逐步 +1，**封顶 6**。查询 `encounterSlotCount(save)`。页签 / 面板标题用「主线」。章节行写 `第 N 章`，下面一条羊皮纸进度条：填充 `mainLootClaims / 10`（≥10 视觉封顶 100%），条上写 `本章战利品 n/10`，满 10 写 `战利品 10/10 · 下一条Boss`。主动重抽叫 **探索**（消耗金币）。订单类型用现有：`enemy` 敌人、`blackMerchant` 黑心商人、`passerby` 路人、`pawn` 当铺、`artisan` 工匠委托、`bulkBuy` 收购。工匠委托等非战斗单这期仍留在主线板，不删。每种带 5 档品质 `gray / green / blue / purple / orange`（灰绿蓝紫橙）。**探索永不刷灰**（权重 0）；绿最多、蓝次之、紫少、橙很少。品质倍率写在 `QUALITY_TABLE`：绿=基准 1.0，蓝需求 1.25 / 产出 1.4，紫 1.6 / 2.0，橙 2.2 / 3.0（性价比 = 产出/需求递增）。高品质需求更高、产出更高、更赚。成交 / 敌人已领奖的格子盖章（成交 / 完成 / 已领）并换底色，主按钮不可再点。失败/拦截提示用点击附近漂字，不占死栏。

### 6.0 章节与本章 Boss

- 存档：`mainChapter` 从 1 起；`mainLootClaims` 计**成功领取敌人格战利品**的次数（0 起）。再战 / 战败 / 未领不 +1。旧档缺字段 hydrate 成第 1 章、计数 0。
- 本章普通敌人走杂兵 / 精英池（橙档品质不再单独当首领）。`mainLootClaims` 到 **10** 后，**下一张新刷出的敌人**是本章 Boss（不把第 10 次领取的那张单改成 Boss）。
- 板上已有未领的本章 Boss 时不再强制刷第二只。Boss 战败 / 再战留在本章；计数保持 ≥10，继续把 Boss 当下一张 / 当前 Boss 单。
- 领取本章 Boss 战利品后：`mainChapter + 1`、`mainLootClaims = 0`，清掉旧章剩余敌人格（交易单留下），按新章补板。
- 敌人三围是单一战斗底版 × 品质倍率 × 阶级倍率 × `MAIN_CHAPTER_COMBAT_MUL`（HP / ATK，约每章 +8%）。品质代表强弱；时长由 HP / ATK / SPD / 超时 / 章节倍率决定，不再有近远 / 强弱。

### 6.1 探索

`EXPLORE_COST_TABLE` 表驱动：`[8, 10, 12, 14, 16]`，按 `exploreCount` 取档，超出末档钉在 16。金币不够不能探索，不换板。成功则扣金、`exploreCount++`，用 `save.rngState` 按 `ENCOUNTER_KIND_WEIGHTS` / 品质权重**独立掷**种类与品质（不再用 `seed×槽位` 取模，空格都能刷出敌人），**只替换可刷新格**；保留格占原位。板子按当前科技格数生成；战斗中 / 胜可领 / 败可再战可暂超过目标格数，仍封顶 6。

敌人格：

- **保留不刷新**：战斗中、胜可领、败可再战。
- **可以刷新替换**：未开打，以及战利品已领取。

交易格（黑心商人 / 路人 / 当铺 / 工匠委托 / 收购）：未完成与已完成都可刷新。当前没有未结清的跨格交易。

### 6.2 敌人

新刷出的交物单只要求 **1 种物品**。消耗数量表驱动：

```
qty = max(1, round(base × QUALITY_TABLE.demandMul × chapterNeedMul(chapter) × bossMul))
chapterNeedMul(chapter) = 1 + (chapter - 1) * 0.15
```

`base` 绿档第 1 章约 2，可按物品微调（`MAIN_NEED_BASE`）。物品从 `MAIN_NEED_ITEM_POOL`（meal / ore / fish / tool / roast / stew / potion 等已有产物）掷 1 个；交易单用该类型表里的第一种。本章 Boss **只再 × `CHAPTER_BOSS_NEED_MUL`（1.25）加数量**，不再叠第二种物品。战利品 `lootGold` 仍乘品质产出倍率，Boss 另乘战利品倍率。章节需求倍率单独函数，不绑战斗 HP 倍率。旧档 `distance` / `power` hydrate 时读完即丢；已有 needs / loot 原样留下（再战中的多物品敌不改写）。

流程（行军门闩已换成战斗；交易单不动）：

1. 对照物资看补给；缺的标红。货不够不能开战，**不扣货**。
2. 点「战斗」弹框：只列休息中工人（`assignment===null` 且不在战斗中）；最多选 **2** 人；HP≤0 不可选。品质只写在工人**名字字色**（`WORKER_QUALITY_TABLE.color`，白档等浅色用偏深棕）和角标上，列表项不再套品质色边 / 左侧色条 / 粉彩底；选中单独金底金边，与品质字色无关。并列 `LvN`、HP 与战斗属性图标，不写 ATK / SPD。弹框只负责选人。工人页名册仍用品质色边框 / 角标。
3. 确认开战：扣光该格补给，`departCount++`、写 `lastDepartAt`，写入 `combat`。**当时不发金币。** 出战不算派驻工坊。
4. 双方三围 HP / ATK / SPD（SPD = 每隔多少秒出手）。工人：`WORKER_COMBAT_BY_TIER` 品质底版 + `CLASS_COMBAT_MOD` 小修正，再叠战斗等级（见 2.2；本档生产表不动）。敌人：`ENEMY_COMBAT_BASE`（单一底版）× `ENEMY_COMBAT_QUALITY_MUL` × `ENEMY_COMBAT_RANK_MUL` × 章节倍率（HP / ATK；阶级同时拉长出手间隔）。墙钟目标（两名约 5 档工人，合计约 240 伤/分）：无弱点时杂兵约 10 分钟可胜、精英约 12～15 分钟可胜、首领通常战败（打死或超时）；命中弱点（×1.2～×1.5）后杂兵约 6～8 分钟、首领约 20 分钟可胜。
5. 时间轴出手，走同一套 `applyTick` / 墙钟（在线离线相同）。多工人共砍一敌；敌人优先打当前 HP 比例最低的工人。超时按阶：`COMBAT_TIMEOUT_BY_RANK` 杂兵 / 精英 900 秒（15 分钟），首领 1800 秒（30 分钟）；`COMBAT_TIMEOUT_S` = 1800。胜负时刻记最后一次出手，而不是本次 tick 的 `now`。
6. 敌人另有表驱动弱点（杂兵 2～3，精英 / 首领 3～4；灰绿蓝=杂兵，紫橙=精英；本章 Boss 单独强制首领，橙不自动当首领）。阶级同时改战斗倍率与超时。卡面弱点行只读该单战斗态 `weaknesses` / `revealedWeaknesses`（开战不另掷一份）；元素图标按属性分色（火红、冰蓝），避免火被看成水滴。卡面先全是 `?`，工人出手时只揭示**自己命中的**弱点。未命中伤害 ×1、不揭示。命中 1 条 ×1.2，命中 2 条 ×1.5；只按出手工人自己的属性计，两人属性不合并。再战同一单保留 `revealedWeaknesses`；换新敌 / 刷掉本单清空。
7. 卡面显示敌我血条、三围、弱点行小图标（未揭示仍 `?`）、状态（战斗中 / 胜可领 / 败可再战）。出手 / 揭示弱点 / 胜负走该订单卡本地漂字（同工坊站卡 `stationTips`：按遇敌 id 叠条上浮淡出，只在主线页渲染），不拉长卡内战报列表。`combat.logs` 仍写入存档给逻辑用。选人弹框：品质看名字字色 + 角标，选中金高亮，并列 `LvN`、HP、属性图标，不写 ATK / SPD。订单卡「消耗 / 获得」各写一行（敌人：消耗 `needs`，获得 `lootGold` 金并注明战斗后领），不再写成「A → B」。可生产物资可点，切到底栏工坊并选中 `itemProducerStation` 主产站；金币与产量 Buff 不可点。
8. 胜：点「战利品」领表驱动 `lootGold`，不加物资，并给本场参战名单发 XP（成功消息可带「工人获得经验」）。败：不发金、不发 XP；工人 **带伤**写回 `hp`，回休息；可再战（再战不回满血，沿用敌当前血；仍扣补给、重选人）。
9. 仅休息回血：`assignment===null` 且不在战斗 → 每 10 秒 +1 HP，至 `hpMax`。派站不回血。

`marchEndsAt` 不再驱动主流程。旧档已出发且仍有行军墙钟、未领奖 → hydrate 成胜可领。旧档已 `departed` 且没有 `marchEndsAt`（当时已发过补给金）→ `lootClaimed`。旧档已扣货未开战（`submitted`）→ 开战免再扣。

### 6.3 黑心商人 / 路人 / 当铺 / 工匠委托 / 收购

五种交易互斥，卡面标题用中文名，只渲染该类型允许的按钮。品质与章节已在生成时写入需求 / 产出。玩家交物侧（敌人 needs、委托 / 收购 / 路人 wants、当铺 pawnWants）以及黑心商人 buyOffers 都只写 1 种物品；路人 offers 仍可以是另一种。卡面同样分行：黑心商人消耗金币、获得物资；路人消耗 wants、获得 offers；当铺消耗 pawnWants、获得金币；工匠委托消耗 wants、获得产量 Buff；收购消耗 wants、获得 `rewardGold` 金。

1. **黑心商人**（kind `blackMerchant`）
   - 只提供：玩家花金币购买对方货物
   - 不以物易物、不以物换钱
2. **路人**（kind `passerby`）
   - 只提供：以物易物
   - 不收金币买、不以物换钱
3. **当铺**（kind `pawn`）
   - 只提供：以物换钱（交出列出的物资，按价表换金币）
   - 报价表驱动：`pawnUnitGold = max(1, floor(sellGold * PAWN_RATE))`，`PAWN_RATE = 0.75`，略低于 `sellGold`；品质再乘产出倍率
   - 列出可典当物品与报价，确认后扣货加金；货不够失败、不扣错货
   - 不购买、不以物易物
4. **工匠委托**（kind `artisan`）
   - 提交指定成品，**只**给工坊临时产量 buff，不加金币、不奖物资（配方系统未就绪，先不做限时配方）
   - buff 写入 `workshopBuff`，站点速度乘 `buffMul`，到期失效；卡面「获得」只写产量与时长
5. **收购**（kind `bulkBuy`）
   - 高价收指定成品：玩家给物品换金币
   - `bulkUnitGold` 用 `BULK_BUY_RATE = 1.15`，单价优于当铺

成交后该格 `completed`（敌人领奖后 `lootClaimed`）。货不够 / 金币不够则失败。物资装得下任意换得货物，不再因「满」失败。

旧存档 `kind: 'shady'` / `'pawnshop'` 迁成 `blackMerchant` / `pawn`；通用 `kind: 'merchant'`：有收购+换得字段则迁成路人；只有金币购买则迁成黑心商人；否则默认路人。缺品质的旧格补 `green`。

### 6.4 开局与旧存档

新档生成初始 1 格主线订单，章节 1、战利品计数 0。hydrate / 探索按 `encounterSlotCount` 收或补格；旧 6 格板若还没点主线订单格大科技，会收到 1 格，但战斗中 / 胜可领 / 败可再战优先留下。旧存档若仍是单格出发（`currentOrderId` / `orderIndex` / `orderSubmitted`），按当前格数生成并把旧需求迁进第 0 格敌人（旧档已扣货则内部记一笔，开战不再扣）。

## 7. 日循环与离线

- 1 tick = 1 秒。
- 1 游戏日 = 1440 秒（24 分钟现实时间）。只做显示，不改公式。
- 在线每秒 `applyTick` 一次；离线按秒数连跑同一个 `applyTick`。
- 离线上限 **8 小时**（`OFFLINE_CAP_S = 28800`）。超过的部分丢掉。
- `settleOffline` 对比结算前后物资 / 站点 / 金币，生成摘要。boot 与 `visibilitychange` 回前台时 catch-up。有变化时写入一条未读「离线收益」消息（时长、主要产出等），**不再强弹顶栏大摘要条**。顶栏「消息」按钮有未读红点。

`localStorage` 键名：`idea5Idle`。整份 `Save` JSON。

科技树见 `src/sim/tech.ts` 的 `TECH_TABS`：三页签 `production` / `combat` / `affairs`（生产 / 战斗 / 事务）各自独立线性层。每层 2～3 个选项、同行同价；买任意 1 个解锁上一层（更低序号层已买过至少 1 个，或本层已有旧档点亮则可补买同行），无互斥加价，最终都能买齐。层自下而上排：第 1 层在屏幕最下。共用 `techPoints` 灵感。事务第 1～5 层各占一个实装选项：探路哨岗 / 市集执照 / 斥候驿站 / 远望烽台 / 商队路引，分别把主线订单格 1→2→3→4→5→6。生产第 2 层 `workshopRules`（工坊规章）与第 3 层 `artisanArchive`（工匠密录）接入同站两人冲突倍率。战斗页与其余选项先占位（扣灵感、无效果）。灵感来自任意站完成周期，以及骑士等级提升（`src/sim/knightLevel.ts`）。图纸可进物资，不当灵感来源。`techEffectValue` 与抽人/离线/探索/速度/合并仍恒 no-op；主线订单格只走 `encounterSlotCount`。旧 `unlockedTechIds`：能对上新表的 id 留下并保留效果，对不上的丢掉，灵感不扣。每站仍最多 2 人，工具仍挂在站上。
