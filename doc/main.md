# 骑士工坊 · 主体

纯前端挂机。定位：**抽工人、排流水线、同站堆人加速**。主线敌人是补给开门闩后的时间轴战斗（HP / ATK / SPD），交易单不动。

工程对齐同作者 idea3_hospital：Vue3 + TypeScript + Vite + Pinia + Vitest，`src/sim` 纯逻辑，`src/ui` 薄门面，在线与离线都走同一个 `applyTick`。不复制医院的房间 / 污染 / 病人。GitHub Pages 为 project site，Vite `base` 为 `/idea5_idle/`，在线地址 https://sung1011.github.io/idea5_idle/ ，推 `main` 即部署。

另见：[生产定稿](production.md)、[分阶段落地](todo.md)、[站点等级与品类](stationProgress.md)。七工坊、工人双槽、钓鱼细则与明确不做以 production 为准。第 2 期已落地采集四差异；第 3 期已落地锻造软失败与工具槽；第 4 期已落地烹饪食物槽与生产 Buff；第 5 期已落地炼金占位（耗草 / 猎副产出 `potion`，效果不填）与打磨。炼金效果数值仍后补。

游戏定名 **骑士工坊**（仓库名 `idea5_idle` 可保留）。主界面按竖屏手机壳排：去掉大标题桅杆；顶栏粘性资源 HUD（金币 / 钻石 / 工人数 / 骑士等级 / 灵感芯片可横向滑，右侧消息未读红点 + 设置图标）；底栏固定四页签，图标在上、文案在下，选中金底，并吃 `env(safe-area-inset-bottom)`。全局壳左下挂半透明短条悬浮新手任务（主线 · n/5，目标写明工人/工坊/主线/科技事务，五步领完不渲染），当前未完成步在对应页给目标按钮加青色脉冲（描边+轻微外发光，约 1.2s 循环），不另开任务页。页签无路由库，底栏从左到右：**工坊** | **工人** | **主线** | **科技**（新档或无效记忆回落主线，默认页仍是主线）。不做跨站状态清单、日时钟或玩法说明。设置弹框分页：**统计**（游戏日 / 已运行 / 探索 / 出发 / 抽人 / 骑士等级 / 离线次数）、**常规**（音乐 / 音效开关，先记本地 preference）、**GM**（初始化、加资源、满品质工人、加灵感 1万、重置科技并全额返还灵感，仅调试）。钻石 `diamonds` 是高级代币占位，默认 0。缺料空转不再整卡酒红描边；制造站「消耗」行与主线订单同形（`物品名 ×需求 / 拥有`），可生产物资可点跳到主产工坊，缺的那件轻微闪烁（约 1.25s，`prefers-reduced-motion` 关掉）。制造站卡片只列当前这次会扣的物品（选中品类 `costs` / `altCosts`，炼金只列当前会走的那一组），不写「消耗库存」标题；采集站无消耗则不显示该块。产出不再常驻「产出库存」，完成吞吐时带 `stationId`，只在工坊页对应站卡上漂「获得 …」（一次吞吐多种合并；有工坊金币则并入「金币 +N」）；空杆 / 遇险 / 软失败无产出则漂该站 notice。切走其它页不显示这类产出漂字。金币不足等全局拦截仍用 `floatTips`。主界面不再卖货。没有银行页，也没有容量条。不存 `recentGains`。

## 1. 定位

一存档是一个账号：共用物资库存、工人名册、统一时钟。金币只服务生活（抽人 / 探索 / 黑心商人购买消耗，当铺典当 / 收购 / 敌人战利品 / 工坊吞吐按产出 `craftGold` 加金），不接战斗。

- **Worker**：抽取获得。带 `qualityTier` 1～10（颜色档）与 `classId`（生活职业，战斗只做三围小修正）。同档两人可合成升一档。存 `hp` / `hpMax`；hydrate 缺则按表满血。另存战斗 `level`（从 1）与当前级内 `xp`；hydrate 缺则 Lv1、xp 0。另存 `combatAttrs`（剑枪匕首斧弓杖 / 火冰雷风光暗），槽数看品质。
- **生活站点（定稿七站）**：挖矿 `mining`、锻造 `forging`、狩猎 `hunting`、烹饪 `cooking`、采药 `herbalism`、炼金 `alchemy`、钓鱼 `fishing`。采集 / 制造各有核心差异，经同一套物资库存连成流水线。细则见 [production.md](production.md)。
- **现码已是七站骨架**：采矿、锻造（工具）、狩猎、烹饪、采药、炼金、钓鱼。伐木 `woodcutting` 废弃并藏入口；旧档已派伐木的工人 hydrate 撤到休息。
- 锻造**只造各站专属工具**（`STATION_TOOL_DEF` 的 `miningTool01`… / `herbalismTool01`… 等），已删除铜/铁/秘银通用 `tool` / `ironTool` / `mithrilTool` 配方。先选类型（镐/锤/猎具/锅/镰/瓶架/竿），再选要造的 tool01–20；未解锁不能造，下拉只列出已解锁 + 下一档预览置灰。造的解锁看**锻造站自身等级** `min(20, forgeStation.level)`：锻造 Lv1 可造各站工具1，Lv5 可造到工具5。目标站等级不再挡住能不能造。工坊站卡用下拉选用具（首项「无」），不装备/换装/卸下。选中那一把给该站小幅效率，每次成功吞吐耗 1；「无」不耗，耗尽回「无」。各站**使用**工具仍按目标站 `floor(stationLevel/5)`，Lv1–4 只能选「无」。**武器线搁置**。工人只留 `foodSlot` 装烹饪食物，同时仅 1 个生产 Buff；到期槽内还有则自动吃 1 份刷新，可手动吃 1，可立即换食覆盖。偶遇补给收食物 / 工具 / 矿。每站最多 2 人；同站满两人可在工坊站卡合并升档。

三条主轴：

1. **跨站流水线（定稿）**：挖矿 → 矿石 → 锻造各站专属工具 → 工坊下拉 `selectedToolId`；钓鱼 / 狩猎 → 烹饪食物 → 工人 `foodSlot`；采药 / 狩猎副产 → 炼金出 `potion` 占位（第 5 期已能做，效果不填）。第 2 期采集已按节点 / 空杆 / 遇险 / 稳采结算；第 3 期工具槽已改成站级下拉与分级解锁；第 4 期食物槽续 Buff，与站工具效率乘区分开（同 `effectId` 只在食物 / 炼金之间取最强）；炼金解析口 `potionEffectValue` 本阶段恒为 0。
2. **同站堆人加速（迅雷手感）**：同一站点最多派 2 人。人数项仍是线性（2 人基础为 1 人的 2 倍），满 2 人再乘冲突倍率（未研究 ×0.5，工坊规章 ×0.75，工匠密录 ×1）。第 3 人派入失败。
3. **堵点可见**：原料见底提示。物资无容量，堆再多也不停产。不恢复银行容量停产。

### 2.2 Worker

工具挂在站点 `selectedToolId`（工坊站卡下拉，首项「无」；本站只生效一把）；第 4 期工人 `foodSlot` 续期：

```ts
Worker = {
  id,
  name?,
  classId?,          // 生活职业；战斗 = 品质底版 + 职业小修正
  qualityTier,       // 1～10；抽人默认白档 1；旧档缺字段 hydrate 补 1
  assignment: stationId | null,  // 每站最多 2 人；出战不算派驻
  foodSlot: FoodSlot | null,   // 烹饪产物；同时仅 1 个生产 Buff；到期自动吃 1 份刷新；可手动吃 1；可立即换食覆盖
  hp, hpMax,         // 战斗生命；hydrate 缺则满血
  level,             // 战斗等级，从 1；hydrate 缺则 1；抽人 / spawn 默认 1
  xp,                // 当前级内经验；仅战胜领战利品发放；hydrate 缺则 0
  combatAttrs,       // 克制属性；白 0、绿蓝青 1、紫+ 2；同人不重复
}
```

品质 10 档写在 `WORKER_QUALITY_TABLE`，UI 用档色一眼区分。无灰；白为最低档；粉插在橙后、红前：

| 档 | id | 名 | 色 |
| --- | --- | --- | --- |
| 1 | `white` | 白 | `#c4bba8` |
| 2 | `green` | 绿 | `#3e9a2a` |
| 3 | `blue` | 蓝 | `#3a7ad9` |
| 4 | `cyan` | 青 | `#1aa6a6` |
| 5 | `purple` | 紫 | `#8a4ecf` |
| 6 | `orange` | 橙 | `#e67a12` |
| 7 | `pink` | 粉 | `#ff7aad` |
| 8 | `red` | 红 | `#d43a3a` |
| 9 | `gold` | 金 | `#d4a017` |
| 10 | `rainbow` | 彩 | `#e83e8c` |

旧档只存 `qualityTier` 数字。存档用 `workerQualityRev` 标记色表：缺字段或 `< 2` 视为旧灰表（1灰 2白 3绿 4蓝 5青 6紫 7橙 8红 9金 10彩），hydrate 按 `1→1、2→1、3→2、4→3、5→4、6→5、7→6、8→8、9→9、10→10` 迁一次后盖成 `2`。已是新表的档不再映射，避免绿被再压成白、粉被压成橙。新 7 粉无人自然拥有。

合成：只允许**同一工坊、同档**两人。入口在工坊站卡工人行右侧（满 2 人才显示）。消耗两人，产出 1 个高一档新人；满档（10）不能再升。不同档 / 不同站 / 不满 2 人失败。工人食物槽卸回物资（只退槽内剩余份）；站上工具留下。新人留在原站、空槽。站卡合成按钮固定显示「合成」。职业在「新档可用池」里用 `rngState` 随机：`minQuality ≤ 新档` 的 `classId` 都能抽到，可能是两人已有的，也可能是池里其它职业。1 档池仍是力工 / 匠人 / 游民；更高档依次解锁矿工、渔夫、猎手、厨子、药农、铁匠、炼金师、管事、骑士。名字仍按 `WORKER_NAME_POOL` 与 `nextWorkerId` 轮转。本档品质只区分外观与职业池，不改吞吐公式。战斗经验均分：`avgTotal = floor((totalXp(A) + totalXp(B)) / 2)`，新人按 `fromTotalXp(avgTotal)` 写 `level` + `xp`。克制属性：抽人 / hydrate 只往已解锁空槽掷互不重复的 id；合成保留第一人已有属性，只补新解锁空槽。旧档缺字段按品质补；白档空数组，卡面灰字「无克制属性」；有属性只显示 20×20 正方形小图标芯片（title/aria 仍用中文名）。

战斗等级只改三围，不改生产 / 品质。出战三围 = `WORKER_COMBAT_BY_TIER` + `CLASS_COMBAT_MOD`，再叠等级：相对 Lv1 每级 HP +4%、ATK +3%、出手间隔 ×0.99（最快不低于该底版的 70%）。`xpToNext(L) = round(20 * 1.25^(L-1))`，可连升；`totalXp` / `fromTotalXp` 供合成。升级重算 `hpMax`，当前 `hp` 按升级前比例留到新上限。XP **只**在战胜后点「战利品」时发给本场 `combat.workerIds` 里仍在名册的工人（含已写回且 HP≤0）；败战 / 未领 / 战斗中不发。发放量按阶级底值（杂兵 8 / 精英 14 / 首领 24）+ 每章 +1。`workerLiveStats` / `fillWorkerHp` / `beginEnemyCombat` 都走带等级的算法。

站工具不再走 `effectId` 词条，只给该站速度乘区 `1 + 序号 × 3%`（只生效一把）。食物特效仍按 `effectId` 取最强，不同 ID 并存；炼金走同一套 `effectId` 解析口（`potionEffectValue`），本阶段恒为 0。同一 worker 同时只能派一个站。每站最多 2 人。旧档工人 / 站上 `toolSlot` hydrate 一律回物资，不再装配；同站超过 2 人的撤到休息。工人页只留食物槽，没有工具装配。

### 2.3 站点

定稿七站（差异与去向见 [production.md](production.md)）：

| 站点 | `stationId` | `kind` | 核心差异 | 产出 → 去向 |
| --- | --- | --- | --- | --- |
| 挖矿 | `mining` | gather | 节点生命，挖空等恢复 | 矿石 → 锻造 |
| 锻造 | `forging` | craft | 配方 + 软失败 | 各站专属工具 → 工坊下拉 |
| 狩猎 | `hunting` | gather | 遇险检定（非战斗） | 肉 → 烹饪；血/牙/眼 → 炼金 |
| 烹饪 | `cooking` | craft | 产出食物 | 食物 → `foodSlot` → 生产 Buff |
| 采药 | `herbalism` | gather | 无限稳采 | 草 → 炼金；香料 → 烹饪 |
| 炼金 | `alchemy` | craft | 一次性消耗草 / 血 / 牙 / 眼（效果未定） | `potion` 占位 |
| 钓鱼 | `fishing` | gather | 可空杆；期望更慢；随机；渔场品阶墙 | 鱼 → 烹饪；杂物低权 |

**旧站**：伐木 `woodcutting` 已移出主界面与派站按钮。hydrate 把已派伐木的工人撤到休息。`wood` 旧档数量保留、可在偶遇出手，不再产出。不做制皮 `leatherworking`。

现码 UI 主玩七站，工坊页左侧七站竖签（采矿 / 锻造 / 狩猎 / 烹饪 / 采药 / 炼金 / 钓鱼，钓鱼末签），切签右侧只显示该站一张卡。竖签底色按该站显示进度自下而上浅绿/金填充（与站卡同一套 `useVisualProgress` / `station.progress`+speed；停产/冰冻偏灰并停住）；选中金边叠在进度层上。在岗每人一颗品质色点（`WORKER_QUALITY_TABLE.color`，约 7px），空岗不画点。无骨架折叠。锻造只造各站专属工具（先选类型再选已解锁档，下一档预览置灰），可软失败；工坊站卡用下拉选该站 20 种专属工具（首项「无」，未解锁置灰），工人页只选食物与数量装 `foodSlot`，可手动吃 1。挖矿有节点生命，挖空后该矿恢复中可换其它已解锁矿；钓鱼按渔场掉落（可空杆、初级不出高阶）；采药无限稳采草/香料；狩猎周期结束做遇险检定（短暂停手 / 本次减产，无战斗 UI）。烹饪：烤鱼耗鱼出 `meal`，烤肉耗肉出 `roast`（开局可做），香料炖耗肉/鱼+香料出 `stew`（Lv5）。炼金耗草或猎副产（血/牙/眼）出 `potion`，不能装食物槽、不加生产 Buff。每站最多 2 人；满两人可在该站卡合并。站卡 header 只写品类与周期，不写「n/2 人」；header 下在岗工人同一行横排（0～2）：品质角标 + 品质色名字（白档深棕）+ `LvN`，满 2 人时右侧出合并；无人则一行淡字「空岗」。

采矿 / 锻造 / 钓鱼 / 狩猎 / 烹饪各站独立等级与 XP。采矿 / 锻造 / 钓鱼 / 狩猎开局只解锁第 1 品类，每 5 级解锁下一档；烹饪开局解锁烤鱼与烤肉，Lv5 解锁香料炖。高阶是新物品，不是换皮。整站只选一个品类，堆人加速当前档。采药 / 炼金仍单一品类。周期全部 ×4（不足 20s 提到 20s）。升级 `xpToNext(L) = round(100 * 1.45^(L-1) * 0.175)`，铜/铁/秘银每次 1/2/3 XP，到 Lv5 累计 133，前期升档墙钟比旧周期+旧 XP 大约快 30%。细则见 [stationProgress.md](stationProgress.md)。

每站另有表驱动 20 种专属工具（id `miningTool01`…，名称可占位如「采矿工具1」「采药工具2」）。**使用**解锁种数 `min(20, floor(stationLevel / 5))`：Lv1–4 为 0，只能选「无」；Lv5 第 1 种，Lv10 第 2 种，Lv100 满 20。用具下拉首项「无」。未解锁即使有库存也不可选。选中那一把：`speed × (1 + 序号 × 0.03)`，只生效一把；每次成功吞吐从物资耗 1，「无」不耗，库存见底自动回「无」。**锻造**解锁看锻造站等级 `unlockedTier = min(20, forgeStation.level)`：锻造 Lv1 可造各站工具1，Lv5 可造到工具5；目标站等级不挡造。`selectedForgeToolId` 只列出当前类型下已解锁 + 下一档灰项；消耗/时长占位：1–5 铜矿 32s，6–10 铁矿 36s，11–20 秘银矿 40s（第 1 种可用渣滓）。旧档 `tool` / `ironTool` / `mithrilTool` 与站/工人 `toolSlot` hydrate 回物资，进其它库存，不自动选中。

原料不足则空转并提示缺哪几样，够则一次性扣光 `costs` 再产出。产出不受库存数量限制。

偶遇敌人新单改收食物 / 工具 / 矿。旧档武器需求仍可成交。

## 3. 同站堆人加速

进度记在站点。每秒：

```
stackFactor(n) = n
speed = (1 / cycleS) * stackFactor(n) * stationConflictMul
progress += speed
progress >= 1 → 完成一次吞吐，progress -= 1
```

例：采矿 `cycleS = 20`

- 1 人：无冲突，`speed = 0.05/s`，20 秒出 1 矿
- 2 人未研究：人数项 0.10/s 再 ×0.5 → 与 1 人相当
- 2 人已点「工坊规章」：×0.75；已点「工匠密录」：×1.0（消除冲突）
- 3 人：`stationSpeed` 仍按 n 倍算（玩法派驻上限 2）

`cycleS` 取当前 `selectedCategory`。没人的站不推进，且 `assignedCount <= 0` 时立刻把 `station.progress` 置 0（站卡条与左侧竖签进度底同一字段，一起归零）；再派人从 0 涨。原料见底（锻造高阶档缺对应矿也算）时进度冻结，并写 `stallReason: emptyInput`。产物再多也不停产，没有满仓。

## 4. 流水线

定稿主轴见 [production.md](production.md) 第 3～4 节。现码主轴：采矿把当前品类的矿推进物资（挖空等恢复）→ 锻造扣对应矿出工具；钓鱼按渔场随机出鱼/杂物/空杆、狩猎出肉 → 烹饪出熟食/烤肉/香料炖进 `foodSlot`；采药出草/香料、狩猎出副产 → 炼金扣草或血/牙/眼出药剂占位。相邻站同时有人不再加速、也不额外掉主产物。`STATION_DEF.neighbors` 已清空，结算不读。

配方 `costs`：`IoRule[]`，三种形态同一套结算。

1. 单料 1 个：`[{ itemId: 'ore', qty: 1 }]`
2. 同料 n 个：`[{ itemId: 'ore', qty: n }]`
3. 多料：`[{ itemId: 'ore', qty: n }, { itemId: 'wood', qty: m }]`

`takeCosts` 先看齐再扣；缺任一原料整单不扣，提示列出缺的物品。铜器另有 `altCosts`（渣滓）。

堵点（只剩缺料，没有满仓）：

- 当前锻造品类 `costs` 见底 → 锻造空转（铜档工具仍可用渣滓；铁/秘银只缺对应矿）
- 当前烹饪菜谱原料见底 → 烹饪空转（烤鱼缺鱼；烤肉缺肉；香料炖缺肉/鱼或香料）
- 草与猎副产都见底 → 炼金空转（卡面写「草 / 血 / 牙 / 眼见底」）
- 采集站不因物资数量停工

制造站卡片就近列出当前这次会扣的物品，不写「消耗库存」标题；采集无消耗则不列。产出靠吞吐完成时挂在对应工坊站卡的本地「获得」漂字，不走全局居中 `floatTips`，不常驻产出列表。没有独立物资区、容量条 / 快满 / 满仓。数量可无限（仅 `MAX_SAFE_INTEGER` 软夹，防溢出，UI 不表现满）。库存仍写 `save.bank`。

## 6. 主线（章节 + 探索 + 六种订单 + 品质；敌人是战斗）

主线订单格数随科技变：**初始 1 格**，探路哨岗 / 市集执照 / 斥候驿站 / 远望烽台 / 商队路引 五道大科技逐步 +1，**封顶 6**。查询 `encounterSlotCount(save)`。页签 / 面板标题用「主线」。章节行写 `第 N 章`，下面一条羊皮纸进度条：填充 `mainLootClaims / 10`（≥10 视觉封顶 100%），条上写 `本章战利品 n/10`，满 10 写 `战利品 10/10 · 下一条Boss`。主动重抽叫 **探索**（消耗金币）。订单类型用现有：`enemy` 敌人、`blackMerchant` 黑心商人、`passerby` 路人、`pawn` 当铺、`artisan` 工匠委托、`bulkBuy` 收购。工匠委托等非战斗单这期仍留在主线板，不删。每种带 5 档品质 `gray / green / blue / purple / orange`（灰绿蓝紫橙）。**探索永不刷灰**（权重 0）；绿最多、蓝次之、紫少、橙很少。品质倍率写在 `QUALITY_TABLE`：绿=基准 1.0，蓝需求 1.25 / 产出 1.4，紫 1.6 / 2.0，橙 2.2 / 3.0（性价比 = 产出/需求递增）。高品质需求更高、产出更高、更赚。成交 / 敌人已领奖的格子盖章（成交 / 完成 / 已领）并换底色，主按钮不可再点。失败/拦截提示用点击附近漂字，不占死栏。

### 6.0 章节与本章 Boss

- 存档：`mainChapter` 从 1 起；`mainLootClaims` 计**成功领取敌人格战利品**的次数（0 起）。再战 / 战败 / 未领不 +1。旧档缺字段 hydrate 成第 1 章、计数 0。
- 本章普通敌人走杂兵 / 精英池（橙档品质不再单独当首领）。`mainLootClaims` 到 **10** 后，**探索必出本章 Boss**（不把第 10 次领取的那张单改成 Boss，也不再等加权碰巧掷出敌人）。空位补板、探索替换可刷新格，都先落这只 Boss。领满 10 次后若板上有已领敌人格 / 已完成交易格，会立刻回收一格刷出 Boss，免得格子满、只刷交易单时永远轮不到。本章 Boss 品质至少橙色：生成时若掷到橙以下则抬到橙，橙及以上按原品质表保留；旧档低于橙的本章 Boss 在 hydrate / 确保时同样抬到橙。
- 场上同一时间最多 **1** 只本章 Boss。一旦刷出（待战 / 战斗中 / 可领奖），探索与补板都不得清掉它，也不得再刷第二只。已领奖的本章 Boss 不再占这个名额。
- 领取本章 Boss 战利品后：`mainChapter + 1`、`mainLootClaims = 0`，**场上其它订单保持不动**，不 `resize` / 清板 / 强制重刷非 Boss 单。新章再重新累计战利品，满 10 再出下一章 Boss。
- 敌人三围是单一战斗底版 × 品质倍率 × 阶级倍率 × `MAIN_CHAPTER_COMBAT_MUL`（HP / ATK，约每章 +8%）。品质代表强弱；时长由 HP / ATK / SPD / 超时 / 章节倍率决定，不再有近远 / 强弱。

### 6.1 探索

`EXPLORE_COST_TABLE` 表驱动：`[8, 10, 12, 14, 16]`，按 `exploreCount` 取档，超出末档钉在 16。金币不够不能探索，不换板。成功则扣金、`exploreCount++`，用 `save.rngState` 按 `ENCOUNTER_KIND_WEIGHTS` / 品质权重**独立掷**种类与品质（不再用 `seed×槽位` 取模，空格都能刷出敌人），**只替换可刷新格**；保留格占原位。`mainLootClaims ≥ 10` 且板上没有未领本章 Boss 时，**第一格新刷强制敌人本章 Boss**，不再走种类加权。板子按当前科技格数生成；战斗中 / 胜可领 / 败可再战 / 未领本章 Boss 可暂超过目标格数，仍封顶 6。

敌人格：

- **保留不刷新**：战斗中、胜可领、败可再战，以及未领的本章 Boss（含待战）。
- **可以刷新替换**：未开打的普通敌人，以及战利品已领取。

交易格（黑心商人 / 路人 / 当铺 / 工匠委托 / 收购）：未完成与已完成都可刷新。当前没有未结清的跨格交易。

### 6.2 敌人

新刷出的交物单只要求 **1 种物品**。消耗数量表驱动：

```
qty = max(1, round(base × QUALITY_TABLE.demandMul × chapterNeedMul(chapter) × bossMul))
chapterNeedMul(chapter) = 1 + (chapter - 1) * 0.15
```

`base` 绿档第 1 章约 2，可按物品微调（`MAIN_NEED_BASE`）。物品从 `MAIN_NEED_ITEM_POOL`（meal / ore / fish / tool / roast / stew / potion 等已有产物）掷 1 个；交易单用该类型表里的第一种。本章 Boss **只再 × `CHAPTER_BOSS_NEED_MUL`（1.25）加数量**，不再叠第二种物品。战利品绿档基准 `LOOT_GOLD_BASE = 6`，`lootGold` 再乘品质产出倍率，Boss 另乘战利品倍率。章节需求倍率单独函数，不绑战斗 HP 倍率。旧档 `distance` / `power` hydrate 时读完即丢；已有 needs / loot 原样留下（再战中的多物品敌不改写）。

流程（行军门闩已换成战斗；交易单不动）：

1. 对照物资看补给；缺的标红。货不够不能开战，**不扣货**。消耗不足时，开战 / 战斗 / 再战 / 交付 / 交易等主按钮置灰（与「战斗中」同一套 disabled），点击漂「物资不足」；物资够则恢复可点。
2. 点「战斗」弹框：只列休息中工人（`assignment===null` 且不在战斗中）；最多选 **2** 人；HP≤0 不可选。品质只写在工人**名字字色**（`WORKER_QUALITY_TABLE.color`，白档等浅色用偏深棕）和角标上，列表项不再套品质色边 / 左侧色条 / 粉彩底；选中单独金底金边，与品质字色无关。并列 `LvN`、HP 与克制属性图标，不写 ATK / SPD。命中当前已揭示弱点 1 条标「推荐」、2 条标「强烈推荐」，0 条不标。弹框只负责选人。工人页名册改成按品质分组的小图标网格，点开底部详情。
3. 确认开战：扣光该格补给，`departCount++`、写 `lastDepartAt`，写入 `combat`。**当时不发金币。** 出战不算派驻工坊。
4. 双方三围 HP / ATK / SPD（SPD = 每隔多少秒出手）。工人：`WORKER_COMBAT_BY_TIER` 品质底版 + `CLASS_COMBAT_MOD` 小修正，再叠战斗等级（见 2.2；本档生产表不动）。敌人：`ENEMY_COMBAT_BASE`（单一底版）× `ENEMY_COMBAT_QUALITY_MUL` × `ENEMY_COMBAT_RANK_MUL` × 章节倍率（HP / ATK；阶级同时拉长出手间隔）。墙钟目标（两名约 5 档工人，合计约 240 伤/分）：无弱点时杂兵约 10 分钟可胜、精英约 12～15 分钟可胜、首领通常战败（打死或超时）；命中弱点（×1.2～×1.5）后杂兵约 6～8 分钟、首领约 20 分钟可胜。
5. 时间轴出手，走同一套 `applyTick` / 墙钟（在线离线相同）。多工人共砍一敌；敌人优先打当前 HP 比例最低的工人。超时按阶：`COMBAT_TIMEOUT_BY_RANK` 杂兵 / 精英 900 秒（15 分钟），首领 1800 秒（30 分钟）；`COMBAT_TIMEOUT_S` = 1800。胜负时刻记最后一次出手，而不是本次 tick 的 `now`。
6. 敌人另有表驱动弱点（杂兵 2～3，精英 / 首领 3～4；灰绿蓝=杂兵，紫橙=精英；本章 Boss 单独强制首领，橙不自动当首领）。阶级同时改战斗倍率与超时。卡面弱点行只读该单战斗态 `weaknesses` / `revealedWeaknesses`（开战不另掷一份；生成订单或 hydrate 旧档时按阶级写入初始暴露，不重掷已有弱点表）。元素图标按属性分色（火红、冰蓝），避免火被看成水滴。开战前卡面预暴露：杂兵 2、精英 1、首领 0（全 `?`）。工人出手打中尚未暴露的弱点仍揭示并保留。未命中伤害 ×1、不揭示。命中 1 条 ×1.2，命中 2 条 ×1.5；只按出手工人自己的属性计，两人属性不合并。再战同一单保留 `revealedWeaknesses`；换新敌 / 刷掉本单清空。
7. 卡面显示敌我血条、三围、弱点行小图标（未揭示仍 `?`）。不渲染 `statusText` 绿字行（待战 / 战斗中 / 胜可领 / 败可再战 / 已领都不出绿字）；按钮灰态、「战斗中」按钮文案、红色已领章保留。敌我 HP 与工人页同一套 `hpBar`：条内居中 `HP: {hp}/{hpMax}`，条外只写名字与 ATK / SPD。敌人出手打工人时立刻把伤害写回 `save.workers[].hp`，工人页图标上的血条战斗进行中实时跟着掉；战斗结束 `writeBack` 仍会再写一遍。出手 / 揭示弱点 / 胜负走该订单卡本地漂字（同工坊站卡 `stationTips`：按遇敌 id 叠条上浮淡出，只在主线页渲染），不拉长卡内战报列表。命中弱点的漂字写属性中文名加「暴击」（一条 `枪 暴击`，两条 `枪 火 暴击`），不写「弱点×」；未命中仍只漂伤害。`combat.logs` 仍写入存档给逻辑用。选人弹框：品质看名字字色 + 角标，选中金高亮，并列 `LvN`、HP、属性图标，不写 ATK / SPD；命中当前已揭示弱点 1 条标「推荐」、2 条标「强烈推荐」，0 条不标。订单卡「消耗 / 获得」各写一行（敌人：消耗 `needs`，获得 `lootGold` 金并注明战斗后领），不再写成「A → B」。消耗行写 `物品名 ×消耗 / 拥有`（例：`铁矿 ×3 / 12`），不足用弱提示色并轻微闪烁（约 1.25s，减少动效时关掉）；获得行仍分行。可生产物资可点，切到底栏工坊并选中 `itemProducerStation` 主产站；金币与产量 Buff 不可点。
8. 胜：点「战利品」领表驱动 `lootGold`，不加物资，并给本场参战名单发 XP（成功消息可带「工人获得经验」）。败：不发金、不发 XP；工人 **带伤**写回 `hp`，回休息；可再战（再战不回满血，沿用敌当前血；仍扣补给、重选人）。

### 6.3 黑心商人 / 路人 / 当铺 / 工匠委托 / 收购

五种交易互斥，卡面标题用中文名，只渲染该类型允许的按钮。品质与章节已在生成时写入需求 / 产出。玩家交物侧（敌人 needs、委托 / 收购 / 路人 wants、当铺 pawnWants）以及黑心商人 buyOffers 都只写 1 种物品；路人 offers 仍可以是另一种。卡面同样分行：黑心商人消耗金币、获得物资；路人消耗 wants、获得 offers；当铺消耗 pawnWants、获得金币；工匠委托消耗 wants、获得产量 Buff；收购消耗 wants、获得 `rewardGold` 金。

1. **黑心商人**（kind `blackMerchant`）
   - 只提供：玩家花金币购买对方货物
   - 不以物易物、不以物换钱
2. **路人**（kind `passerby`）
   - 只提供：以物易物
   - 不收金币买、不以物换钱
3. **当铺**（kind `pawn`）
   - 只提供：以物换钱（交出列出的物资，按价表换金币）
   - 报价表驱动：`pawnUnitGold = max(1, floor(sellGold * PAWN_RATE))`，`PAWN_RATE = 0.75`，略低于 `sellGold`；品质再乘产出倍率
   - 列出可典当物品与报价，确认后扣货加金；货不够失败、不扣错货
   - 不购买、不以物易物
4. **工匠委托**（kind `artisan`）
   - 提交指定成品，**只**给工坊临时产量 buff，不加金币、不奖物资（配方系统未就绪，先不做限时配方）
   - buff 写入 `workshopBuff`，站点速度乘 `buffMul`，到期失效；卡面「获得」只写产量与时长
5. **收购**（kind `bulkBuy`）
   - 高价收指定成品：玩家给物品换金币
   - `bulkUnitGold` 用 `BULK_BUY_RATE = 1.15`，单价优于当铺

成交后该格 `completed`（敌人领奖后 `lootClaimed`）。卡面不再出「这笔买卖已成交 / 委托已完成 / 这笔收购已成交」绿字，只留按钮灰态（成交 / 完成）与红色盖章。货不够 / 金币不够则失败。物资装得下任意换得货物，不再因「满」失败。

旧存档 `kind: 'shady'` / `'pawnshop'` 迁成 `blackMerchant` / `pawn`；通用 `kind: 'merchant'`：有收购+换得字段则迁成路人；只有金币购买则迁成黑心商人；否则默认路人。缺品质的旧格补 `green`。

### 6.4 开局与旧存档

新档生成初始 1 格主线订单（第 0 格固定绿档当铺「铜矿当」，消耗铜矿 `ore` ×2，奖励按 `pawnUnitGold` / `rewardGold`；探索可刷掉），章节 1、战利品计数 0。空板 hydrate 同样补这张；旧档已有板不强制插入。hydrate / 探索按 `encounterSlotCount` 收或补格；旧 6 格板若还没点主线订单格大科技，会收到 1 格，但战斗中 / 胜可领 / 败可再战优先留下。旧存档若仍是单格出发（`currentOrderId` / `orderIndex` / `orderSubmitted`），按当前格数生成并把旧需求迁进第 0 格敌人（旧档已扣货则内部记一笔，开战不再扣）。

## 7. 日循环与离线

- 1 tick = 1 秒。
- 1 游戏日 = 1440 秒（24 分钟现实时间）。只做显示，不改公式。
- 在线每秒 `applyTick` 一次；离线按秒数连跑同一个 `applyTick`。
- 离线上限 **8 小时**（`OFFLINE_CAP_S = 28800`）。超过的部分丢掉。
- `settleOffline` 对比结算前后物资 / 站点 / 金币，生成摘要。boot 与 `visibilitychange` 回前台时 catch-up。有变化时写入一条未读「离线收益」消息（时长、主要产出等），**不再强弹顶栏大摘要条**。顶栏「消息」按钮有未读红点。

`localStorage` 键名：`idea5Idle`。整份 `Save` JSON。

科技树见 `src/sim/tech.ts` 的 `TECH_TABS`：三页签 `production` / `combat` / `affairs`（生产 / 战斗 / 事务）各自独立线性层。每层 2～3 个选项、同行同价；**每个节点都可配置 `maxLevel` 并记存档 `techLevels`**，未满级可对同一节点再点（每层同行同价，扣 1 次灵感）。该层任意节点 `level≥1` 即解锁上一层（或本层已有旧档点亮则可补买同行），无互斥加价，最终都能买齐。层自下而上排：第 1 层在屏幕最下。共用 `techPoints` 灵感。图标叠 `level/maxLevel`（未买 `0/N`，点满用已激活样式且不可再点）。

`maxLevel` 约定：已实装订单格（探路哨岗 / 市集执照 / 斥候驿站 / 远望烽台 / 商队路引）与冲突节点（工坊规章 / 工匠密录）先 `maxLevel=1`，图标走 `0/1`→`1/1`，避免破坏现有平衡；占位节点 `maxLevel=5`，只扣灵感、记等级、无玩法效果。订单格效果按等级叠加（每级 +1 格，封顶 6）；当前已实装订单格都是 1 级，与「点亮 1 个 +1 格」相同。冲突仍是规章 ×0.75、密录消除，**不新开冲突多级线**。战斗页与其余选项先占位。灵感只来自新档初始 20 与骑士等级提升（`src/sim/knightLevel.ts`），工坊完成周期不再加灵感。图纸可进物资，不当灵感来源。`techEffectValue` 与抽人/离线/探索/速度/合并仍恒 no-op；主线订单格只走 `encounterSlotCount`（按订单格科技 `level` 求和）。旧 `unlockedTechIds`：能对上新表的 id 写成 `level=1`（不超过 `maxLevel`）并保留效果，对不上的丢掉，灵感不扣。每站仍最多 2 人，工具仍挂在站上下拉。
