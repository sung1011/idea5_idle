# 工坊精简预览

默认工坊仍是左工作区 + 右战斗/休息。下面三版只改这一页的排布，不改生产、派岗、抽人和存档。

打开方式：在游戏地址后加查询参数，再点底栏「工坊」。

| 参数 | 版本 |
| --- | --- |
| 不加，或 `?workshopDemo=current` | 现状 |
| `?workshopDemo=a` | A 轻量减法 |
| `?workshopDemo=b` | B 主操作聚焦 |
| `?workshopDemo=c` | C 分区重排 |

带了 `workshopDemo` 时，顶上会出现「现状 / 轻量 / 聚焦 / 分区」，点选即切换，不重开存档。加 `workshopShot=1` 只是藏这条切换，布局仍按 `workshopDemo`。

- **A**：六站骨架不动。封闭和详情收进每站「更多」；只有一种产出时不再画下拉；四格药剂收成一行「药剂 n/4」；空的战斗区不占标题；休息标题改成「休息 n」；底栏六条细血条变矮变淡。
- **B**：最上是大号「在岗 n/6」和一颗「抽工人」。六站收成进度条。休息、药剂、站务、战斗进底下一排，点开才展开。底栏细血条让开。
- **C**：上面六站只留谁在岗和进度；中间一行是在岗、队首或堵队、伙食、抽工人；站务、休息名单、药剂槽、战斗区收进底下一排。底栏细血条让开。
