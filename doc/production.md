## 1. 六工坊

`StationKind = 'gather' | 'craft'`。采集三站各有一条核心差异；制造三站走配方。

| 站 | `stationId` | `kind` | 核心差异 | 产出 → 去向 |
| --- | --- | --- | --- | --- |
| 挖矿 | `mining` | gather | 节点生命，挖空等恢复 | 矿石 → 订单 / 金币；荒晶 → 铭刻 |
| 铭刻 | `inscription` | craft | 配方 + 软失败 | 荒晶 → 一次性符文 → 开战装槽 |
| 狩猎 | `hunting` | gather | 遇险检定（非战斗） | 肉 / 鱼 → 烹饪；血 / 牙 / 眼 → 炼金；杂物低权 |
| 烹饪 | `cooking` | craft | 产出食物 | 食物进物资 → 营地 `restFoodId` → 入休息残血回血 |
| 采药 | `herbalism` | gather | 无限稳采 | 草 → 炼金；香料 → 烹饪 |
| 炼金 | `alchemy` | craft | 一次性消耗草 / 猎副产 | 按炼金等级解锁后随机药剂批次 → 营地 4 槽短按点用 |

```ts
type StationId =
  | 'mining'
  | 'inscription'
  | 'hunting'
  | 'cooking'
  | 'herbalism'
  | 'alchemy'

/** 旧站。仍可能出现在旧档，不当现玩法站。 */
type DeprecatedStationId = 'woodcutting' | 'fishing'
```


UI 主列六站，底栏「工坊」默认三层：上方六站各 1 槽，左侧深色木条从上到下铺满整张站卡且各卡同宽，站点图标单独一行并放大，站名在图标下一行，旁边是在岗苦工、同一行的进度条和效率，点站卡大面板派工或排队，详情用小图标或长按打开，产出在详情里选。站点不再封闭。详情没有撤出和换人，撤人只走站卡右上角气泡里的「清空」。站卡上不常驻产出下拉，进度条和「效率 N%」同一行（进度在左占满剩余宽度，效率在右固定宽度、右对齐，数字等宽，按三位数预留，50% 与 100% 切换时文字和进度条都不跳；条约 12px 高、1px 边；`stationCraftPickOptions` 文案与 `stationCraftLabel` 相同：选中品类产出用「、」连接，无产出用品类名；选项值是品类，未解锁置灰不可选；只有一项时仍显示当前产出并禁用）。工作区站槽是圆形种族头像 48（描边 3px，图在圆框内铺满，描边和底色按品质，可带 NEW）、名字约 20、等级约 18，品质色点一并放大。战斗区名单侧栏头像 24、选人等弹出面板 32，描边都是 2px。营地弹框里的苦工头像 48，品质色圆框约 4px（直径的 9%，比工坊更饱和），外圈再加 1px 深色细描边；紫、橙及以上带淡淡外发光。工坊站槽描边仍是 3px。每排 4 格。详情在岗每个苦工名字前是中号种族圆头像 32（描边 2px，底色和框色按品质）。详情制造进度按当前这件的已用/总时长平滑推进，条上写百分比，旁边写剩余时间；一件做完归零并开始下一件，钳在 0～100%。没苦工、缺料或采集暂停时条停住变灰并写明原因（空岗写「无苦工在岗」）。切页或从后台回来按真实经过的时间对齐。旧站卡不放大。详情标题栏下方显示站等级和经验条，数字是当前经验/升到下一级所需，升级公式不变。详情用小图标或长按打开（消耗 / 速度 / 站经验 / 品类，以及产出选择）。站序采药→炼金→狩猎→烹饪→采矿→铭刻（`STATION_ORDER` 共用）。离开工坊后，底栏上沿按同一顺序显示六格细血条，有人按 `workerWearHp/hpMax`（满绿、中金、低红），空岗整条灰色斜纹并带红色描边，有人按在岗苦工铺色，约 5px，不挡页签、不跳站；工坊页收起这排。工坊六站左侧底板铺满卡高（图标一行、站名在下一行），旁边是在岗苦工、同一行的进度和效率，不再有队列条。任意页点底栏营地都打开同一个营地弹框：标题「营地 · 可派 N」，四列苦工格，底部只有伙食和抽苦工，右上角关闭；有人出战才在工坊侧栏显示「战斗 N」。工坊页最底、底栏导航上方钉着一条木框骨饰快捷栏，不随站卡滚动，列表底部留空以免挡住最后一行。四个槽是大一号圆角大槽：图标居中、名字在下、右下角绿色圆形数量；按下下沉闪光、角标跳一下；生效时外圈倒计时光环；数量为 0 变灰、红角标 0，点了提示去哪里做；从没有变成有时呼吸两下。空槽淡灰。没有底部营地 / 站务 / 战斗一排。旧组签双站大卡无底栏入口。`woodcutting` / `fishing` 废弃或藏入口，见第 7 节。详情没有撤出和换人，撤人只走站卡右上角气泡「清空」；右上角「？」打开该站说明，文案表在 `src/ui/stationHelp.ts`，弹层与资源栏同款分层字段：名称、怎么玩、产出、消耗，有特殊点再写注意，末行体力为「在岗体力影响效率：正常 100%，残血 80%，空血 50%。残血进入营地才吃当前伙食；药剂点槽给在岗救急。」。详情层写「效率 N%」（空岗 100%，在岗按体力乘区）。在岗槽空血（`hp/hpMax ≤10%` 且未在战斗）加深红描边并轻闪（`crew-empty-hp`，对齐左栏空转）；残血不另闪，苦工右栏不加。账号首次在岗效率跌破 100% 漂一次并记 `workshopHpEfficiencyTipShown`。

## 2. 各站核心差异

迅雷堆人、`cycleS`、站点 XP / 品类骨架仍沿用现式（周期 ×4 且 ≥20s，升级曲线见 stationProgress）。下面只定**差异规则**；具体数值第 2 期表驱动。

### 2.1 挖矿 `mining`（采集）

节点有生命。每次成功吞吐扣 `nodeHp`；`nodeHp <= 0` 后写入 `recoverAt`（恢复完成时的 `elapsedS`），恢复完成前该节点不产矿（进度冻结，可换其它已解锁矿）。恢复满后 `nodeHp = nodeHpMax`，`recoverAt = null`。铜档 `recoverS = 50`，铁 / 秘银仍 90 / 120。各矿品类节点存在 `miningNodes`，当前档镜像为 `miningNode`。

```ts
type MiningNodeState = {
  categoryId: CategoryId
  nodeHp: number
  nodeHpMax: number
  /** 挖空后恢复完成的 elapsedS；未空为 null */
  recoverAt: number | null
}
```

产出：`ore` / `ironOre` / `mithrilOre`（沿用现档）+ 同档双掉 `wildCrystal` 荒晶。矿石只进物资，去向订单 / 地精当铺金币（铜矿 `craftGold` 仍是 0，采矿金币中性）。荒晶是铭刻唯一原料，不进主线新单池。

### 2.2 铭刻 `inscription`（制造）

表驱动 `RUNE_DEF` + **软失败**：周期走完后做一次失败检定。成功从已解锁且付得起的配方里随机一种，扣荒晶并出一批符文（`batch` 区间 + 科技额外产出）。失败扣部分荒晶（`INSCRIPTION_SOFT_FAIL_TAKE_RATIO` 0.5，不足 1 按 1），无成品，给少量 XP（`xpPerCycle * 0.5`，至少 1）。不炸炉、不停站、不额外扣苦工。成功率 `INSCRIPTION_SOFT_FAIL_CHANCE`（0.1）。旧名 `forging` / `completeForgingCycle` 只作文案与兼容导出。

产出**只**是一次性战斗符文（`runeSharp` 锋锐 / `runeArmor` 厚甲 / `runeBlood` 血酬 / `runeBreak` 破障 / `runeSwift` 迅击 / `runeInsight` 洞悉）。解锁看铭刻站等级：Lv1 锋锐+厚甲（荒晶×2，批次 1–2，XP1）；Lv5 血酬+破障（荒晶×2，批次 1–2，XP2）；Lv10 迅击+洞悉（荒晶×3，批次 1，XP3）。周期 32s。没有 20 档工具下拉，不按吞吐耗工具，`selectedToolId` 恒空。武器线仍搁置。

```ts
type SoftFailRoll = {
  chance: number
  outcome: 'ok' | 'softFail'
}

type RuneItemId =
  | 'runeSharp'
  | 'runeArmor'
  | 'runeBlood'
  | 'runeBreak'
  | 'runeSwift'
  | 'runeInsight'
```

符文进 `bank` 堆叠。出战 / 增援每人 **1 空槽**：点槽出弹层列全部种类 + 库存 + 短效果；开战扣选中的符文，效果只打携带者、只本场。助战同一套槽。洞悉多名携带只揭示一次。战后清槽。旧档 `*ToolNN` / 通用 `tool` `ironTool` `mithrilTool` / `forgedTools` hydrate 转荒晶（专属/初级×2、中阶×3、秘银×4），每满 4 件再给起步锋锐，半额厚甲；清空 `selectedToolId` / `selectedForgeToolId` / `selectedToolType` / `forgedTools`。

| id | 名 | 本场效果 |
| --- | --- | --- |
| `runeSharp` | 锋锐 | 造成伤害 ×1.25 |
| `runeArmor` | 厚甲 | 受到伤害 ×0.75 |
| `runeBlood` | 血酬 | 战后该苦工额外战斗 XP（胜负都发，`RUNE_BLOOD_XP`=8） |
| `runeBreak` | 破障 | 命中弱点额外扣 1 盾 |
| `runeSwift` | 迅击 | 出手间隔 ×0.85 |
| `runeInsight` | 洞悉 | 开战多揭示 1 条弱点（全场一次） |

### 2.3 狩猎 `hunting`（采集）

周期结束做 **遇险检定**，不是战斗：无回合、无死亡、不接 `classId` 成长。遇险：掉本周期产出、短暂停手 `HUNTING_HAZARD_PAUSE_S`（8s），库存有熟食则再耗 1 份；仍给站 XP。遇险不再单独扣血，体力只看该站掉血词条。猎物按品类：野猪 / 狼 / 鹿（Lv1 / Lv5 / Lv10）。**狩猎真战斗 TODO，本轮不做。**

```ts
type HazardRoll = {
  /** 表驱动失败率 */
  chance: number
  outcome: 'ok' | 'hazard'
}
```

产出：

| `itemId` | 去向 |
| --- | --- |
| `meat` | 烹饪 |
| `fish` | 烹饪（原钓鱼主产物并入） |
| `junk` | 物资低权（原钓鱼杂物并入） |
| `blood` | 炼金 |
| `tooth` | 炼金 |
| `eye` | 炼金 |

本版不做制皮，不出皮革，不设 `leatherworking`。

### 2.4 烹饪 `cooking`（制造）

配方消耗鱼 / 肉 / 香料等，产出食物进物资。营地弹框里点伙食，选一种共用食物（`save.restFoodId`，默认 null）。残血（hp/hpMax ≤30%）苦工**进入休息**时，若已选且物资至少 1 份，扣 1 并回血（meal 25% / roast 40% / stew 55% hpMax，向上取整，至少 HP>1），并挂同样短的弱生产效果，不占个人槽。未选或没货不吃。已在休息不再续吃，休息回血仍走 `applyRestHeal`。在岗周期和战斗击中不吃。偶遇补给另见第 8 节。

第 1 档 `meal` 烤鱼（耗鱼）；第 2 档 `roast` 烤肉（耗肉，开局可做）；第 3 档 `stew` 香料炖（肉+香料，或鱼+香料，Lv5）。不换皮。

无限稳采：无节点挖空、无空杆、无遇险。周期结束必出货（权重表可调草 / 香料比例，但不允许「什么都不出」）。

| `itemId` | 去向 |
| --- | --- |
| `herb` | 炼金 |
| `spice` | 烹饪 |

### 2.6 炼金 `alchemy`（制造）

一次性消耗：做成即从配方扣光原料。药剂按炼金站 `stationLevel` 解锁，已解锁种类里等概率随机一种，再按 `POTION_BATCH_RANGE` 给一批进物资（巫毒回春剂 8–14、嗜血药剂 4–8、先祖续命汤 5–10、背水药膏 4–8、赶工粉 2–5、双份雾 3–6、清醒图腾水 3–6）。解锁表 `ALCHEMY_POTION_UNLOCK`：1 嗜血药剂、2 背水药膏、3 清醒图腾水、4 巫毒回春剂、5 先祖续命汤、6 赶工粉、7 及以上双份雾。空池保底嗜血药剂。等级读不到按 1 级。瓶数区间、配伍札记加成、食物加产、双份雾乘数都不改。狂兽油不进这张表。旧档库存原样保留，不另迁字段，之后按新池产出；GM 一键满级（10）即全解锁。仓库里还没解锁的药剂仍可装配、点用。苦工、工具、站 XP 仍按原站规则。药剂不能当营地伙食，必须装进营地弹框队列下方的 `potionSlots`（4 槽）后点槽使用，无 CD；只打当时在营地的苦工，在岗 / 战斗中 / 助战不吃这口，营地没人不扣瓶并漂「营地没有苦工可用药」。回血药在营地全员满血时不扣瓶，漂「营地苦工已满血」。工坊页和底栏不再放槽。装配列表按提效、加血分组（空组整组隐藏），每种名称前有对应单色图标，和已装槽都点 i 看效果，气泡里有药剂才显示「卸下」。槽自上而下三行：图标、名称、数量；空槽是淡灰空位。图标与工坊六站、底栏同一套 16×16 单色：巫毒回春剂骷髅药瓶、嗜血药剂带血滴的獠牙、背水药膏药膏罐加盾、清醒图腾水小图腾柱、先祖续命汤冒灵气的汤碗、赶工粉粉包加闪电、双份雾两团雾气，狂兽油另有自己的图标。`potionEffectValue` 仍恒 0；速度改走苦工身上的 `potion`（嗜血 ×1.5、狂兽油 ×2 叠乘，赶工粉缩短下一轮 40%），下一批倍率走这名苦工的双份雾。存档版本 6，账号级 `potionBuffs` 不再保留。旧档通用 `potion` hydrate 成 `salve`；旧档 `focusDraft` / `wardElixir` 库存与已装槽迁成 `doubleMist` / `rushPowder`；旧档 `warDrum` 槽清空。清醒图腾水只奶营地未满血者里血量比例最低的 1～2 人（按 HP/hpMax 升序，平局按 id；第 1 人 30% hpMax，第 2 人 20% hpMax），只有 1 人未满血只回 30%，营地没有受伤者不扣瓶。巫毒回春剂营地全员立刻回 10% hpMax，背水药膏：HP≤30%max 抬到 40%，否则立刻回 5%；加血都先抵劳损债再补生命，加到上限时债清零。嗜血随机 5 人、狂兽油随机 3 人，持续 3 分钟，效果跟人走。赶工粉给队首起 3 人，双份雾只给队首的下一轮。续命汤给喝下时在营地的人，每 10 秒回 5%，持续 2 分钟，派出去仍然生效。主线等随机要药的单子只抽当前已解锁种类，`anyPotion` 仍在；工匠 / 批量收购固定要巫毒回春剂，不改。站卡「？」写当前池，以及下一种在几级解锁（7 级起写已全部解锁）。

原料走 `ALCHEMY_COST_OPTIONS`：草或猎副产（`blood` / `tooth` / `eye`）任一 1 个即可，优先扣草。旧「耗木出药剂 + 渣滓」已废。

## 3. 物流

站间仍共用 `save.bank`（字段名沿用，**无容量**，堆再多也不停产）。

```
挖矿 ──矿石──► 订单 / 金币
挖矿 ──荒晶──► 铭刻 ──符文──► 开战 1 槽（消耗；铭刻未开则槽置灰，点出酋长门槛）
狩猎 ──肉/鱼──► 烹饪 ──食物──► 物资 ──► 营地伙食 ──► 入休息残血回血
狩猎 ──血/牙/眼──► 炼金（药剂）
狩猎 ──杂物──► 物资（低权，可在偶遇出手）
采药 ──草────► 炼金（药剂）
采药 ──香料──► 烹饪
营地 `potionSlots[4]` ──装配后点槽使用（无 CD；只打营地苦工；点 i 看效果，气泡内卸下）
```

制造站缺料 → `stallReason: 'emptyInput'`，现规则不变：先看齐再扣，缺任一不扣。采集站不因库存数量停工。

## 4.1 一站一人（冲突已废）

每站最多 1 人（`STATION_WORKER_CAP = 1`）。在岗正好 1 人时，速度再乘 `SOLO_STAFF_MUL = 1.5`。0 人速度为 0，不乘 1.5。`stationConflictMul` 恒返回 1，站上不再显示冲突提示。

| --- | --- |

### 4.2 劳损与药剂

掉血只来自该站 0～3 条掉血词条（持续损耗 / 随机惊吓 / 完成后掉），每 8 小时游戏时间整站重抽，条数和强度随站等级提高。完成后掉先出货再扣血。`debt≥1` 扣 `floor` 血并减债，可以到 0。到 0 立刻回休息，绷带 + 自动吃饭，不行军；残血不撤岗。满血（`hp >= hpMax` 且 `fatigueDebt === 0`）才能上岗。营地队首未满血挡住自动填岗。回休息进队尾。工坊营地格子按这个顺序排。队首不写数字，满血标「队首」，堵住时第 1 格标「堵队」并压暗后面；从第 2 人起头像左上角标 2、3、4…，满血可派白字，未满血或有劳损灰字。队首离开营地（派去站点、出战，或合成等把队首带走）且后面的人仍按原顺序前移、营地还剩至少 2 人时，格子滑向队首空出的位置，约 0.3 秒；只走掉队首时每人向前一格，原 2 变成绿色「队首」，原 3 变成 2。序号跟着格子走，不另做弹跳。手动改队列顺序不播。只剩 0 或 1 人时不播。滑动期间不能拖着合成，播完恢复。合成若带走队首，先播出队，新人再从外侧滑进队尾。合成新人、战斗结束归队、从站点回营地、抽卡进营地，都用这套进队尾滑动，约 0.3 秒，期间同样不能拖着合成。自动填岗不看封闭。详情「掉血」列出本批词条。旧的按站倍率不再使用。血线三档（`hp/hpMax`）：≤10% 空血 ×0.5，≤30% 残血 ×0.8，＞30% 正常 ×1。详情层写「效率 N%」。工坊页底色读 `hp - fatigueDebt`。已删除站狂暴、战鼓药与站工具。营地 4 槽短按点用药剂（嗜血随机 5 人 ×1.5、狂兽油随机 3 人 ×2、巫毒回春剂全员 10%、清醒图腾水奶最残两人 30%/20%、背水药膏抬残血、双份雾队首下一批、赶工粉队首起 3 人缩短一轮、续命汤每 10 秒回 5%；炼金按站等级逐种解锁，狂兽油手动做）。时效挂在苦工身上，按 `elapsedS`。连招只站内，见 [main.md](main.md) 2.2。

## 5. 苦工双槽

```ts
type Worker = {
  id: string
  name?: string
  classId?: ClassId
  qualityTier: QualityTier // 1～10
  assignment: StationId | null // 每站最多 1 人
  foodSlot: FoodSlot | null   // 旧档；余粮 hydrate 退回物资后恒为 null
  foodBuff?                    // 入休息进食挂的短时效果
  potion?: WorkerPotionBuff | null // 喝药挂在人身上，派到哪站带到哪站
  fatigueDebt: number
  combatAttrs: CombatAttrId[] // 白 0 / 绿蓝青 1 / 紫+ 2；同人不重复
}

type EffectSource = 'tool' | 'food'
type EffectId = string

type EffectInstance = {
  effectId: EffectId
  value: number
  source: EffectSource
}

type ToolSlot = {
  itemId: ItemId
  /** 匹配此站才吃满增效 / 高阶词条 */
  matchStationId: StationId
  affixes: Affix[]
  effects: EffectInstance[]
}

type Affix = {
  affixId: string
  effectId: EffectId
  value: number
}

type FoodSlot = {
  itemId: ItemId
  /** 槽内未吃完的份数（不含当前正在生效的那一份） */
  qty: number
  /** 同时仅 1 个生产 Buff */
  buff: ProductionBuff
  /** 到期墙钟；到期若 qty>=1 则吃 1 份刷新，否则清空 */
  expiresAt: number

}

type ProductionBuff = {
  effectId: EffectId
  mul: number
  durationS: number
}
```

品质 `qualityTier` 1～10，色表 `WORKER_QUALITY_TABLE`（白绿蓝青紫橙粉红金彩，无灰）。抽人默认白档 1；同档未满档只能在营地合成：两人都在营地才行，新人留在营地并固定排到队尾，1 血。教到合成之前拖合失败，漂「还没教你合成」。消耗的两人离开队列；若其中有队首，后面的人先向前移，新人再从外侧滑进队尾。战斗结束归队、从站点回营地、抽卡进营地，也从外侧滑进队尾空位，约 0.3 秒。不同档或满档放不下，不换人。空槽不能拖上岗。没挂自动的站点一下派一轮，正在干再点排队，最多 5 轮；自动线是无限排队：一轮做完回营地队尾，立刻再拉满血队首，不限 5 轮，不再留人常驻。关掉自动时正在做的这一轮按手动收尾。站卡没开自动时右上角数字是在岗人数加后续排队，空站 0，连点到 5；自动开启时显示 ♾️。拖回营地空白不能撤岗。主线 REV 9：任何时候只有一条任务，共 92 步，顺序写死。1 级是招人、采草、再排一轮。升到 2 级后熬药，再合成（合完队尾 1 血；教到合成之前拖合失败，漂「还没教你合成」），然后装药、用药看回血，再出征、挂自动。合伙时若有人还在站上，等他回营地或再抽一名，两名同品质都在营地后再拖。出征若草不够，任务改口让继续点采药站排队，攒够 2 株再开战。点「熬药」任务条只切到工坊炼金站卡（大面板派工）并圈站卡，不打开炼金详情。点「两槽齐备」任务条打开营地，并圈空药剂槽，直到至少 2 个槽装上药剂即可领奖。领到「升到11级：今晚能点一项科技」时提示自动线名额变成 2。狩猎、烹饪、采矿、铭刻的上手任务是点站派工。升到 N 级的任务写成「升到N级：今晚能…」，旁边写「本章：…」，不再罗列一串系统，也不再弹开放卡片。保留的原有 16 步是 20 金加 20 经验（珍草是侦测加 20 经验）。20 级及以前的升级任务奖 20 金和 15 经验，之后奖 24 钻和 10 经验。赶集只认集市板。开采看夺宝累计收获。夺洞记抢夺胜利。割草是短日常，文案是「割到一株珍贵草药就行」。困兽是主线硬仗。夺宝留到 20 级，步骤短。当前任务开放后达成过就保持可领。存档版本升到 6，旧版本整档丢弃并重新开局。新档金币、钻石都是 0，前 8 次抽苦工免费，不再跳过已满足的主线，也不再按玩过的痕迹保留模块。跳过位图记到 93 步。只能在营地同品质合成。工坊上方不再常驻同品质合成提示。成功合成一次后仍记 `fuseDragTipDone`。前期（酋长低于 5 且引导未领完）只在在岗苦工头像旁轮播小教程，同屏 1 条，不挂营地休息和排队队首。回营地的苦工排到队尾，不会堵在队首。过了门槛不再出。合并时苦工食物回物资。职业按新档池随机。自动线不看品质。手动一轮的产出按在岗苦工品质相乘，白档 ×1。克制属性随品质开槽，合成保留已有、只补新槽。新档第一次合成出的 2 档苦工，属性改成悬赏新手单已揭示的剑。旧灰表存档靠 `workerQualityRev` 迁一次。每站最多 1 人（`STATION_WORKER_CAP`）。偶遇敌人弱点、揭示与破防盾见 [main.md](main.md) 6.2。
