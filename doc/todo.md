# 骑士工坊 · 分阶段落地

对照 [main.md](main.md)、[production.md](production.md)。

技术：Vue 3 + TypeScript + Vite + Pinia + Vitest。`src/sim/` 纯逻辑，`src/ui/` 只读状态、发操作。在线与离线共用 `applyTick`。

顶栏最左是玩家头像和名字，点开小层可改。底栏现在是 **工坊 | PVE | PVP | 科技**。PVE 内页签 **战场 | 地牢 | 商场**（本地键仍是 `idea5IdleMainlineTab`，旧值 `mine` 回落战场；底栏 PVE 的内部 id 仍是 `encounters`）。PVP 目前只有夺宝矿洞。新刷守军 50% 0 人（直接无人矿）、20% 1 人、20% 2 人、10% 3 人，已有洞不重掷。花 10 钻刷新非战斗洞，抢夺中的洞留下。订单开战、增援、夺宝开采和抢夺共用开战选人面板。开采不显示符文槽。选中槽位按入队顺序标 1/2/3，增援从已占槽的下一号起。占领后不能补采；一键撤出即放弃成无人矿，储量与倒计时不重置，可再占。无人矿也会被 10 钻刷新刷掉。PVP 顶栏一个「夺宝」页签。矿洞弱点单独一行用属性图标，初始问号，开采或开战揭开；命中真实弱点则该工人开采快 1 秒。储量旁写消失倒计时，矿卡不再另列守军名单。守军是其他玩家快照，不是 NPC。新刷守方随机玩家名，旧洞名字保留；我方默认显示名见习勇者。未开战的快照驻守洞只画守方血条和槽；我方开采洞没在抢夺时也只画守方条，名字是玩家显示名，槽是在采工人。开战守方在上、攻方在下。弱点揭开后留到该洞消失，放弃不清。抢夺进行中当前攻守挂战场血条和出手条，血条是开战编制合计血量，血条下 3 格标 1/2/3（有人/空/亡），点有人看信息，空槽和已阵亡只漂字。夺宝、战场、地牢、商场页签行右上角有玩法说明。问号只写玩法规则（含开采不装符文、抢夺可装、洞种不同掉落偏重不同），不解释守军快照或假玩家；矿洞面板不再铺导语。卡头按砂金洞 / 珠宝洞 / 古玉洞显示。我方开采有一条动态进度和最快约 Ns/次，入库漂获得提示。工坊站行在工人槽和进度条之间显示当前产出短名。

每档先写 `sim` 和测试，再挂一层薄 UI。字段名跟 production 对，不要另起一套。

后做（不挡第一期）：更多配方、微信适配。
