# 车间闲置 · 分阶段落地

对照 [main.md](main.md)。

技术：Vue 3 + TypeScript + Vite + Pinia + Vitest。`src/sim/` 纯逻辑，`src/ui/` 只读状态、发操作。在线与离线共用 `applyTick`。

每档先写 `sim` 和测试，再挂一层薄 UI。

后做（不挡第一期）：更多配方、微信适配。
