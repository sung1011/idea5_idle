# idea5_idle

抽工人、排流水线、同站堆人加速的生活挂机。第一期纯生活，不做战斗。

玩法与字段见 [doc/main.md](doc/main.md)，分阶段见 [doc/todo.md](doc/todo.md)。

## 安装

```bash
npm install
```

## 命令

```bash
npm run dev
npm run build
npm test
```

开发页默认 http://localhost:5173 。存档写在 `localStorage`，键名 **`idea5Idle`**。

测试也可以直接：

```bash
npx vitest run
```
